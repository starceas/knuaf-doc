# 특용작물·허브 가격 조사 경로

이 문서는 가격을 찾을 때 우선 열 경로와 각 경로의 가격 성격을 구분하는 보충 안내다. 출처 ID·해시·발췌·작업 기록은 `source-contract.md`와 `source-intake.md`를 따른다.

> 상태: 사용자 제공 조사 보고서의 경로 관찰(2026-09-07)을 정리한 것이다. 이 문서가 링크의 현재 상태, 현재 가격, 특정 기간의 거래를 실시간 검증한 것은 아니다. 아래 관찰을 현재 사실로 승격하기 전 실제 조회일과 결과를 다시 기록한다.

## 조사 계약

조사 시작 전에 현재 답변에서 다음 맥락을 한 묶음으로 전달한다. 미제공 조건은 미확정으로 명시하고 전부 채워질 때까지 조사 전체를 막지 않는다. 작목·상품 형태·필요한 가격 성격처럼 경로 선택에 필수인 조건이 불명확하면 그 부분만 질문하거나 후보별로 분리해 조사한다.

`작목명·사이트 품목명(별칭 포함) / 상품 형태 / 원산지 / 등급·규격 / 원래 단위·포장중량 / 유통단계·가격 역할 / 지역·시장 / 대상 기간 / 기준일(reference date) / 목표가가 농가수취·경락·중도매인·소매 중 무엇인지`

- 생허브(`fresh herbs`), 건조 약재(`dry medicinals`), 분말·모종은 서로 분리한다. 국산·수입산, 등급·규격, 포장 단위도 섞지 않는다.
- KAMIS에서 바질은 `바실`로도 나타날 수 있다. `로케트 루꼴라`처럼 사이트에 등록된 품목명을 그대로 기록한다. 별칭 확인은 비슷한 작목으로 바꾸는 근거가 아니다.
- 소포장 가격을 kg로 환산해도 대량 납품가나 농가수취가가 되지 않는다. 환산 근거가 없으면 환산하지 않는다.
- 노무비 시간급(원/시간)을 일급(원/일)으로 환산할 때도 임의 시간을 쓰지 않고 명시적 공식 근거와 `unit_conversion` 계약이 있어야 한다 (기본 환산 시간 없음, Q-W-B2 사용자/조사 후 결정 대기).
- **노무비 관측 성별 계약**: 등록 수열에 성별 차원이 없으면 남자(Y열)·여자(Z열) 모두 동일한 관측값을 채운다. 성별 차원(`gender`·`sex`·`성별`)이 있는 수열은 단일 출처 입력 형식(남녀 전체 채우기)에서는 거부된다(남성 수치를 여성 관측으로 복제 금지). 남녀 상승률(`wage_male`·`wage_female`) 입력은 각각 맞는 성별 출처(`wage_male`=남자, `wage_female`=여자)만 사용할 수 있다. 수식 패치 시 생산자(`check_wage_gender`)가 대상 열(남자=AC38, 여자=AD38)과 출처 성별을 엄격히 대조한다 (Ⅳ장 각주는 참고값으로 출력되며 영수증 대조는 하지 않는다).

### 상승률 입력 및 계산 규칙

1. **상승률 결정 원칙 (관측 수열 CAGR 강제)**:
   - 상승률 r은 **확인된 공식 관측 수열의 끝점 연평균 변화율(CAGR)로만 산출**된다.
   - 명시적 `rate` 입력은 검산용이며, 수열 관측값으로 계산된 CAGR과 허용오차(`max(5e-4, 0.05 × |CAGR|)`) 이내로 일치해야 한다.
   - 관측 수열이 없거나 관측값과 다른 임의 계획 가정 r의 직접 입력은 거부된다.
2. **연평균 변화율(CAGR) 산식**:
   - `r = (V_end / V_start)^(1 / (end_year - start_year)) - 1`
   - 가격 하락 시 음수 r도 허용되며, 내부 계산 배율은 `1 + r`이다. 모든 관측값·r·배율은 유한수여야 한다(NaN/Infinity 거부).
3. **기초연도와 적용 횟수**:
   - 계획연도 Y의 배율은 `(1 + r)^(Y - application_base_year)`로 계산한다.
   - 적용 횟수는 계획연도와 적용 기초연도의 연도 차이와 같다 (예: 2022년 기준 단가에 2025년 계획을 적용하면 `2025 - 2022 = 3회` 적용이며 2회가 아님).
   - 이미 기준연도 관측 단가로 입력된 가격에는 첫해에 중복 적용하지 않는다.
4. **이중 적용 금지**:
   - 동일 가격에 상승률을 두 번 곱하지 않는다. 노무비 단가에 임금 상승률을 곱한 뒤, 노무비 총액에 일반물가 상승률을 다시 곱하는 행위는 엄격히 금지된다.
   - 감가상각비와 고정 차입금 원리금 상환액에는 물가상승률을 적용하지 않는다.
5. **판매가 차원 일치 및 계획 권위 원칙**:
   - **계획의 권위**: 사업계획(spec의 `crops`, `region`, `cultivation`, `product`, `channel`, `grade` 등 최상위 선언)이 절대적 기준이다. 보조 차원(`price_dimensions`, `target_dimensions`, 역할별 `target_dimensions`)이 계획과 충돌하면 거부된다(뒤 값 우선 금지).
   - **수열 차원 완전 일치**: 판매가 수열이 선언한 모든 차원(최상위 수열 `unit` 포함)은 계획이 같은 값으로 확정해야 한다(`crop` 필수). 계획에 없는 차원이 수열에 있거나 조건이 다르면 적용을 거부한다.
   - **가격 가정 어댑터**: 판매가 작목(`target_dimensions`)은 문자열(`crop: "봄감자"`), 목록(`crop: ["봄감자"]`), 또는 한글 별칭(`작목: "봄감자"`)을 모두 지원한다. 임금(`wage`)에는 작목이 필수가 아니며 지역(`region` 또는 `지역` 별칭)만 지정할 수 있다.
   - **`전국` 와일드카드 불가**: `전국`도 하나의 고정된 지역값이며 와일드카드가 아니다. 다른 작목을 포함한 목록 멤버십이나 유사 작목으로 대체 적용할 수 없다.
   - 조건 불일치 시 전국 총지수나 다른 작목 단가를 임의 대입하지 말고 "판매가 상승 미반영(확인 불가)"을 **명시 선택**한다 (`{"status": "not_applied", "reason": "확인 불가"}` 또는 `{mode: "not_applied", reason: "확인 불가"}`).
6. **학생 직접 입력 수열(`price_sources`)의 공식 출처 및 엄격 URL 계약**:
   - 학생이 수열을 직접 추가할 때도 엄격한 공공기관 공식 출처 계약을 통과해야 한다:
     - **기관 종류(`agency_kind`)**: 국가통계(`national_statistics`), 중앙정부(`central_government`), 지자체(`local_government`), 공공기관(`public_corporation`), 국공립연구기관(`public_research_institute`) 중 하나 필수.
     - **엄격 HTTPS 공식 URL**: `url` 및 `evidence_url`은 `https://` 프로토콜 필수이며 공인 도메인(`kosis.kr`, `go.kr`, `kamis.or.kr`, `re.kr` 계열)의 정확 일치 또는 `.` 접미사여야 한다.
     - **URL 우회 차단**: 백슬래시(`\`), userinfo(`@`), 공백, 제어문자, NBSP, 443 외 포트, 빈 host/port, 유니코드/IDNA 변형(punycode `xn--`), 불완전 percent encoding, 점 경로(`.`, `..`, `%2e`), 빈 `?`/`#` 등 브라우저와 파서 간 해석이 달라지는 모호한 URL은 입력 단계에서 즉시 거부된다.
     - **필수 필드**: `evidence_locator`, `base_year`(지수는 기준연도 정수, 명목은 null 필수), `unit`, 비어 있지 않은 `dimensions`(dict), `allowed_roles`(목록 필수).
     - **연도 정합성**: 관측 연도와 미확인 연도(`unconfirmed_years`)의 교집합 금지.
7. **확인 불가 원칙**:
   - 통계 공표가 아직 안 되었거나 확인되지 않은 연도(예: 봄감자 2025년, 쌀 소매가 2020년)는 0이나 임의 값으로 보간하지 않고 `확인 불가`로 표기한다.
8. **수식 숫자 표기 및 Excel 정밀도 보존 (`_excel_number`)**:
   - 패치가 수식에 쓰는 상승률 상수는 Excel이 보존하는 정밀도인 **유효숫자 15자리**로 직렬화(절단)되어 기록된다.
   - Excel은 수식 안의 숫자를 최대 15자리까지만 보존하고 나머지를 버리기 때문에, 처음부터 15자리로 맞춰 쓰면 Excel에서 파일을 열고 재저장해도 수식 문자열(토큰)이 달라지지 않아 안전하다.
   - 21자리 이하 숫자는 일반 소수점 형태(고정소수점), 초과 시 지수 형태(`E`)를 쓴다.
   - 영수증 `d8.rates[*]`에는 원래 계산값 `r`(원 CAGR 계산값)을 보존하고, 수식에 기록된 값은 `r_literal` 필드에 별도로 남긴다 (두 값의 차이는 최대 `1.1e-14 * |r|`로 허용오차 `1e-12` 안에서 안전하게 일치).
9. **원예환경시스템 18시트 재무 입력 계약 (`price_contract`)**:
   - 이 공식 통계 계약(`price_contract: "series:general"`)은 특용작물뿐 아니라 **원예환경시스템 18시트 재무 파라미터(자재·경비 연간 상승률 55키)**에도 동일하게 적용된다. 임의의 계획 상승률이나 비공식 출처는 거부되며, 실제 적용값은 공식 관측 수열의 끝점 CAGR로 대체된다.
   - 학생 자재 단가·시설 견적(300키)은 상승률과 분리되어 `source:quote` 출처 계약으로 관리되며, 출력 라벨은 "학생 견적/작성자 직접 조사"(`source_type="author_survey"`)로 명확히 표시된다.
   - 근거 요약 필드(`cost.overhead.source_summary`, `cost.labor.wage_evidence_summary` 등 5키)는 비어 있지 않은 자유 문구를 받지 않고, 검증된 관측 수열 각주와 인용 출처 라벨로 자동 생성된 검증 문구(`source:summary`)만 셀에 반영된다.
   - **생산 증가율 예외**: `sales.y2~y5.growth_rate`는 가격·임금 물가상승률이 아니라 **전년 대비 생산 증가율(생산량 스케일링)**이므로 물가 통계 수열 계약(`price_contract`) 대상이 아니며 기존 동작을 유지한다.

## 조회 순서와 중단

1. 목표 가격 역할에 맞는 위 공적 경로를 먼저 하나 지정한다. 약용작물·산채의 생산지/도매지/소비지 비교는 산림조합, 농가수취·재무 입력은 농사로 조사자료의 품목·연도·단위가 맞는지 확인하고, 경락은 KAMIS 경락, 중도매인 추세는 KAMIS 도·소매로 분기한다. 봉산허브·허브아이 등 개별 업체 게시가는 [참고 불가 (출처 불가)]이므로 조사 출처로 채택하지 않는다.
2. 지정 출처의 검색어·필터·지역·시장·기간·등급을 기록하고 실제 결과 페이지를 연다. 결과가 없으면 사용한 조건을 보존한다.
3. 별칭은 정식명·사이트 품목명처럼 확인된 이름만 시도한다. 바질/바실처럼 확인된 표기를 모두 시도한 뒤에도 없으면 `품목 미등재` 또는 `해당 조건 결과 없음`으로 남긴다. 유사 작목·상위 작목을 임의로 대체하지 않는다.
4. 네트워크·인증서·로그인 오류는 `접속 실패/미확인`이지 `가격 없음`이 아니다. 정한 재접속 또는 다음의 역할 일치 경로까지만 시도하고, 반복적인 무목적 검색은 중단한다.
5. 정한 경로에서 적합한 공개 가격을 확인하지 못했으면 `조사 범위 내 미확인·사용자 확인 또는 견적 필요`로 남긴다. 가격이 세상에 없다는 결론으로 확대하지 않는다. 문의·회원가입·구매를 조사 완료로 간주하지 않는다.

### 상품 부위·재배 방식

당귀의 생근·건근·잎은 별도 상품 형태로 기록한다. 토경·배지경도 구분하고,

생근에서 건근으로 환산할 때는 건조 수율 근거가 필요하다. 잎과 뿌리를
같은 포기에서 얻는 계획은 구역·생산 주기·중복 수확 여부의 근거가 없으면
두 수량을 독립 생산량처럼 더하지 않는다. 검색어 별칭은 확인된 품목명만
추가하며, 다른 작목의 생산성이나 가격을 당귀 값으로 대체하지 않는다.

- 봉산허브·허브아이 등 개별 업체 게시 소매가는 [참고 불가 (출처 불가)]이며 농가수취단가·도매단가·재무입력으로 쓸 수 없다. 비공식 쇼핑몰이나 업체 판매가는 공식 출처로 인정되지 않으며, 가격 조사는 KAMIS·산림조합 등 공식 통계로 좁힌다([source-intake.md](source-intake.md)).
- 핵심 농가수취가격이나 시장가격이 없으면 그 값에 의존하는 손익·현금흐름 판정만 `보류/BLOCK`한다. 확인하지 못한 값을 0이나 임의 가격으로 채우지 않고 "확인 불가"로 남긴다.
- 공개 계약단가가 없으면 `사용자 확인 또는 견적 필요`로 남긴다. 업체에 거래·견적을 묻거나 자료를 보내는 외부 연락은 사용자의 명시적 승인이 있을 때만 하며, 이 경로 안내가 견적 요청을 자동으로 보내지는 않는다.
