# 서식·표기 규칙 (F)

적용 범위: 이 문서는 2020 특용작물 작성요령의 발췌·해석이다. 학교 원문 사실과 내부 해석·사례 관찰을 구분한다. 다른 전공에 이 목차·양식을 자동 적용하지 않는다. 현재 작성·검사 정책은 [thesis-level.md](../thesis-level.md)·[source-contract.md](../source-contract.md)를 따른다. 새 교수 지시는 별도 등록하며, 현행 금칙 게이트는 문서 해석만으로 면제하지 않는다.

출처: 학교 창업논문 작성요령 2020 PDF(sha256 `f60b58b7dcde86eab9f273dd50114ac296d009bd60abb940aaa866a54e866de2`) I. 작성 요령에서 정리한 발췌·해석. 명시적 원문 항목의 발췌이며 내부 권고·보조 해석은 학교 의무가 아니다. 선배·참고 사례 관찰은 학교 의무가 아니다.

DOCX 선언·기계검사와 실제 렌더·한글 최종 확인을 구분한다. 현재 `project.json`에서 미완료인 사용자 마무리만 안내한다. 이미 확인한 항목을 재요구하지 않는다(`../guideline-tracking.md`).
외부 표·그림은 제목 끝 `(출처 : 기관명)`을 제목과 같은 크기로 쓰고, 자체 작성·산출·촬영 자료에는 출처를 쓰지 않는다. 설명은 아래 `주 :` 줄로 분리한다(`../figure-photo-policy.md`). 이는 작업 출처 정책이며 학교 각주 9pt를 출처 크기 규정으로 확대하지 않는다. AI 사진을 생성하지 않는다.
표·그림 제목은 본문 12pt보다 작은 11pt, 괄호 출처도 같은 11pt로 출력한다. 이는 학교 각주 규정과 구분되는 작성 정책이다. 빈 줄·표와 주 묶음·칸 폭 조정·그림 축소의 최종 판정은 [그림·사진 정책 §4](../figure-photo-policy.md)의 실제 Word PDF 렌더 기준을 따른다. DOCX 매니페스트 `layout_review`는 검사 대상과 미실시 상태를 제공한다.

## F1 기본 서식

- F1-01 국문 작성. 한자·영자는 괄호 안에 사용 가능
- F1-02 용지 A4 210×297 mm
- F1-03 여백(mm): 위 20.0 / 아래 15.0 / 머리말 15.0 / 꼬리말 15.0 / 왼쪽 30.0 / 오른쪽 30.0 / 제본 0.0
- F1-04 본문 신명조 12pt, 줄간격 160%, 문단 시작 2칸, 혼합정렬
- F1-05 큰제목 20pt 굵게 / 중간제목 13~18pt 굵게 / 각주 9pt

## F2 학명

- F2-01 작물명 첫 등장에만 학명 전체 기재. 예: Angelica gigas Nakai
- F2-02 두 번째부터 속명 약자. 예: A. gigas Nakai
- F2-03 속명·종명은 이탤릭, 명명자와 var. 등은 로마체

## F3 본문 인용

- F3-01 국문 2인은 `과`, 3인 이상은 `등`
- F3-02 영문 2인은 `and`, 3인 이상은 `et al.`
- F3-03 같은 괄호 안 여러 문헌은 세미콜론으로 구분

    당귀의 생리활성 연구로는 피부노화 (Chung, 2012), 항당뇨 (Kim and Lee, 1996),
    항산화 (Bang et al., 2007), 항염증 (Kim et al., 2012; Park and Kong, 2012)

    품종에 따라 삽목시기가 매우 중요하다고 하였다.

    삽목시기별 발근율 조사에서 품종에 따라 삽목시기가 매우 중요하다고 하였다
    (Park and Kim, 2012; Park et al., 2011).

## F4 단위와 약자

- F4-01 SI 단위 원칙. 로마자 정자·소문자. 예외: L, mL, μL
- F4-02 수치와 단위 사이 한 칸. 예외: 각도·분·초·%·℃
- F4-03 단위에 복수형을 쓰지 않는다. 예: 25 ㎏
- F4-04 인명·지명 등 고유명사는 원어, 연도는 서기
- F4-05 약자·약호는 첫 등장에 완전명칭 병기 후 사용

## F5 표·그림

- F5-01 제목·설명은 한글. 본문을 참조하지 않아도 이해되도록 간결히
- F5-02 일련번호를 붙이고 제목 끝에 마침표
- F5-03 표 표제는 상단 왼쪽, 그림 표제는 하단 가운데
- F5-04 본문에서 표·그림을 참조할 때 번호를 포함한다

### 본문 참조 예시

    표 1에서와 같이 삽목시기와 생장조절제 처리별 발근수에 미치는 영향을 보면 ...
    삽목시기에 따른 생장조절제 처리별 발근율을 표 1에 나타내었다.
    ... 같다 (표 1).

제목 언어(한글/영문)와 `표/그림` 대 `Table/Fig.` 표기는 원문이 충돌한다
(원문 내부 충돌 — 교수 지시가 다르면 그 지시를 따른다).

## F6 제목 번호 체계

    Ⅰ. → 1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮

원문은 단계별 글자 크기를 지정하나 하위가 상위보다 큰 오기가 있다
(원문 내부 충돌 — 교수 지시가 다르면 그 지시를 따른다). 현재 출력 프로필의 위계·크기 선택과 이유를 기록한다. 자동 생성만으로 교수 승인이라고 표시하지 않는다.

## 자동 검사 대상

`scripts/lint_format.py`는 현재 `gg_commands.py`·`gg_document.py`로 연결된다. 학명 앞선 전체표기·수치/단위 띄어쓰기·표그림 번호/참조를 기계 대조한다. 아래 학교 항목 전부를 기계가 보장한다고 해석하지 않는다. 인용 저자수·이탤릭·정확한 위계·시각 배치는 해당 내용·시각 검토로 보완한다.

- 학명 첫 등장 전체 표기 / 이후 속명 약자
- 저자 3인 이상 `등`·`et al.` 사용(내용검토; 해당 자동 검사 확인 불가)
- 표·그림 번호 연속성과 본문 참조 존재
- 수치와 단위 사이 띄어쓰기
- 제목 번호 순서(전공 구조 검사를 제외한 전 단계 자동 판정은 확인 불가)

시각 서식(글꼴·여백·줄간격)은 텍스트로 판정할 수 없다. 최종 HWP에서 사람이 확인한다.

## F6 학교 양식 표의 셀 병합

학교 양식 표는 `가정`·`농장`처럼 여러 행을 묶는 항목이 많다.
**원형 그대로 재현한다.** 병합을 풀어 평평한 표로 만들지 않는다.

마크다운에서 병합을 이렇게 표기하면 `build_docx.py`가 docx 병합 셀로 만든다.

    ^   위 셀과 세로 병합
    <   왼쪽 셀과 가로 병합

### 예 — 표 ◯. 가족구성 및 성장목표 (원문 양식)

    | 구분 | < | < | 2027년 | 2031년 |
    |---|---|---|---|---|
    | 가정 | 본인 | 연령 | | |
    | ^ | ^ | 역할 | | |
    | ^ | 가족의 구성 | < | | |
    | ^ | 생활목표 | < | | |
    | 농장 | 주력작목 | < | | |
    | ^ | 생산방식/경영유형 | < | | |
    | ^ | 경영규모 | 생산규모(㎡) | | |
    | ^ | ^ | 연간매출액(천원) | | |
    | ^ | ^ | 연간순이익(천원) | | |
    | ^ | ^ | 주요 생산시설 | | |

1열이 `가정`(4행)·`농장`(6행)으로 세로 병합되고,
2열의 `본인`은 2행, `경영규모`는 4행 병합된다.
`가족의 구성`·`생활목표`처럼 3열까지 걸치는 항목은 `<`로 가로 병합한다.

### 규칙

- **열 수를 원문과 같게 맞춘다.** 병합 표기 칸도 열로 센다
- 연도 열의 상대 계산은 내부 관행이다. 실제 사업 시작연도·계획기간·재무 통합문서와 일치시킨다(원문의 예시 연도를 학교 의무로 승격하지 않음)
- 단위는 원문대로 (매출·순이익 **천원**, 생산규모 **㎡**)
- 값이 없으면 빈 칸으로 두고 `-`나 `해당없음`을 임의로 넣지 않는다
- 병합 구조가 원문과 다르면 표 자체가 다른 양식으로 보인다. 임의로 단순화하지 않는다
- **첫 행에 `^`, 첫 열에 `<`를 쓸 수 없다.** 병합할 대상이 없다
- 모든 행의 열 수를 같게 맞춘다. 다르면 표가 어긋난다

잘못된 표기는 `build_docx.py`가 `[표 경고]`로 알린다. 경고가 뜨면 표기를 고친다.

### 확인

docx 생성 후 표가 원문과 같은 형태인지 눈으로 대조한다.
텍스트로는 병합 여부를 알 수 없다.

    scripts/build_docx.py <폴더> --in <본문.md> --out <새.docx> --major <전공ID>
    soffice --headless --convert-to pdf <docx> --outdir <폴더>

### 원문 표 목록 (전부 이 표기법으로 재현한다)

작성요령에 실린 표는 6개다. 그중 2개는 `<작성방법>` 안내용이라 논문에 넣지 않는다.
**학생이 만들어야 하는 양식 표는 4개**이고, 여기에 원문에 양식이 없는 표가 1개 있다.

| 표 | 위치 | 병합 구조 | 주의 |
|---|---|---|---|
| 농장 종합 개요 | Ⅱ-1-가 | 병합 없음 (2열) | 항목 5개 고정 |
| 기상환경 | Ⅱ-1-나-1) | 세로+가로 혼재 | 12개월 전체 + 연평균 |
| 재해 | Ⅱ-1-나-6) | 첫 열 세로 병합 | 빈도 3단(가장자주·자주·가끔) |
| 주요농산물 생산현황 | Ⅱ-1-다-2) | 세로 병합 + 출하시장 가로 병합 | 순위별 행 |
| 가족구성 및 성장목표 | Ⅲ-2-가 | 3단 중첩 세로 병합 | 연도 2개 시점 |
| 매출액 근거 | Ⅲ-2-다 | **원문에 양식 없음** | 임의 양식 금지. 작성기준 항목만 서술 |

### 복합 병합 예 — 기상환경 표

한 행에 세로 병합(`구 분`)과 가로 병합(`겨 울`)이 함께 온다.

    | 구 분 | 겨 울 | < | < | 봄 | < | < | 연평균 | < |
    |---|---|---|---|---|---|---|---|---|
    | ^ | 12월 | 1월 | 2월 | 3월 | 4월 | 5월 | ^ | ^ |
    | 평균기온(℃) | | | | | | | | |

1행의 `구 분`이 2행까지 세로로, `겨 울`이 3칸 가로로 병합된다.

**세로로만 합칠 칸에 `<`를 함께 쓰지 않는다.** `연평균`이 1열짜리면 아래 칸만 `^`로 둔다.
가로·세로가 모두 필요한 사각형 병합은 앵커(값이 있는 칸)를 좌상단에 두고,
나머지 칸을 방향에 맞게 `^`·`<`로 채운다. 구현이 블록 전체를 한 번에 합친다.

    | 연평균 | < |      ← 2열 가로
    | ^ | ^ |          ← 아래 행까지 세로. 결과는 2x2 사각형 병합

**원문 기상환경 표는 12개월 전체를 계절별로 묶는다.**
겨울(12·1·2월) / 봄(3·4·5월) / 여름(6·7·8월) / 가을(9·10·11월) + 연평균.
행은 평균기온·최고기온·최저기온·강우량·평균적설량·최고적설량·주된풍향·평균풍속·최대풍속의 9항목이다.
관측장소, 최근 5개년 평균 기간, 초상일과 만상일도 원문 양식에 맞춰 기록한다.

### 표를 만들 때

1. 원문에 양식이 있으면 **그 구조 그대로** 옮긴다. 열을 줄이거나 합치지 않는다
2. 원문에 양식이 없으면(매출액 근거 등) 작성기준 항목만 채우고 임의 양식을 만들지 않는다
3. 만든 뒤 docx로 렌더해 원문과 대조한다. 텍스트로는 병합을 확인할 수 없다
