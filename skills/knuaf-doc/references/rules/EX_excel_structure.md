# 동반제출 엑셀 실측 구조 (참고본 2종 분석)

현행 경계: 아래 수치는 과거 측정 기록이며 이 인수에서 원 엑셀 2종을 재측정하지 않았다. 현재 시트 구조는 `../excel-template.md`, 특용작물 Ⅳ장 전개는 `../specialty-crops/finance-flow.md`를 따른다. 단가·등급비율·수선비·연도·물가 고정값은 학생 사실이 아니며 확인한 공식 근거 없이 승계하지 않는다. 모름·거부는 0이 아니다(`../workflow-order.md`).

출처: 개발 시점에 등록된 선배 참고 엑셀 2종의 XML 측정 기록. **선배 관찰 자료이며 학교 의무·학교 공식 양식이 아니다.**
**두 파일의 시트 구성·라벨·연도블록이 관찰상 일치한다.** 파일 작성자는 서로 다르므로 저자 동일성이나 학교 공식 양식이라는 결론은 내리지 않는다. 공식 템플릿이 있으면 그 파일이 우선한다([excel-template.md](../excel-template.md)). 특용작물전공은 교수님 양식(X01·X02)이 기준이며 이 선배 관찰을 규칙 원본으로 쓰지 않는다([사용자 결정 2026-10-28]).
경비계획 B열 라벨 27개가 두 파일에서 완전히 동일했다.

## 연도 표기 — 실측 확인

두 파일 모두 연도 블록이 **2026년~2030년**이다.

    가. 2026년 / 나. 2027년 / 다. 2028년 / 라. 2029년 / 마. 2030년

판매계획 유통채널 표도 `2026년~2030년` 5개 열.

→ 작성 시점에 맞춰 갱신한다. `창업연도 = 작성연도 + 1` 기준으로
  2026년 작성이면 2027~2031년이 된다(학교 공식 규정이 아니라 참고본 관찰에서 온 관행 — 교수 지시가 다르면 그 지시를 따른다).

## 시트별 구조 (실측)

### 5. 판매계획 — 3단 구성

    가. 연도별 가격 추이        (단위: 원/kg)
       등급별(상품·중품·하품) × 최근 5개년 + 평균가격(AVERAGE)
       수매가와 직거래가를 별도 표로
       중품 = 상품 × 0.8, 하품 = 상품 × 0.6 (수식으로 파생)
       출처를 표 아래 각주로 명시

    나. 유통채널별 판매계획      (단위: %, kg)
       채널(수매시장·직거래·미상품과) × 등급 × 연도
       판매비율(입력) × 생산계획!생산량 = 판매량(수식)
       미상품과 = 100% - 수매계 - 직거래계
       (옛 관찰 칸 이름. 과수가 아니면 "미상품" — 작목 분류별 칸 이름은 ../excel-template.md)

    다. 연도별 매출액 추정       (단위: 천원, kg)
       수량 = 나항의 판매량 참조
       매출액 = 수량 × 가격 ÷ 1000  (천원 단위 환산)

**핵심 패턴**: 비율은 입력, 물량과 금액은 전부 수식. 단가는 가항에서 절대참조($O$7).

### 6. 생산계획 — 근거 서술이 붙는다

    가. 생산량계획
       10a당 생산량 = 생산량 ÷ 재배면적 × 1000  (수식)
       재배면적(입력) / 생산량(입력)

    나. 생산량 산출근거          ← 서술형
       재배면적 / 묘목수(재식기준 주/㎡) / 생산량(kg/주)
       (묘목수는 나무 작목 전제. 초본·버섯은 정식 주수·파종량·재배면적·배지 수 등 — ../excel-template.md)
       생산증가율 / 상품화율 / 합계
       각 항목에 근거 문장을 적는다
       현재 작목·조건의 공식 근거를 확인한다(옛 원고 발췌는 포함하지 않음).

**생산계획은 값 입력 시트지만 근거를 반드시 문장으로 남긴다.**

### 9. 경비계획 — 연도별 블록 반복 (111행)

    [상단 기준값 블록]
    대농기구 수선비 0.06 / 영농시설 수선비 0.005
    수도광열비(천원/10a) 27 / 경영면적 1년차·2년차 / 임대면적

    가. 2026년                 (단위: 천원)
    과목 | 금액 | 산출근거 | 비고
    1. 수선비           =SUM(하위)
      가. 영농시설       ='10.감가상각비계획'!E8*기준    * 구입금액의 0.5% 적용
      나. 대농기구       ='10.감가상각비계획'!I8*기준    * 구입금액의 6% 적용
    2. 수도광열비        =기준*면적/1000*물가계수
    3. 감가상각비        =SUM(하위)                  * 감가상각비계획 참조
      가. 영농시설 / 나. 대농기구 / 다. 생물자산
    4. 임차료  가. 대농기구 / 나. 토지
    5. 위탁영농비  6. 소농구비  7. 기타요금
    합계

    나. 2027년  ← 같은 구조 반복, 전년 참조(=C16) 또는 물가반영(=C18*1.025)

옛 참고본에는 7개 과목·0값이 관찰됐다. 현행 템플릿 과목을 따르고 모름·거부는 0으로 바꾸지 않는다.
**산출근거 열이 필수다.** 모든 계산 셀에 근거 문구를 단다.
**2년차부터는 전년 셀을 참조**해 반복 입력을 피한다.

## 옛 제작 관행 기록 (현재 제출 요구 아님)

1. 시트 17개, 순서 그대로
2. 계산 흐름 단방향 유지 (위 참조도)
3. 연도별 블록을 세로로 반복 (열로 압축하지 않는다)
4. 산출근거 열 필수
5. 단위는 **천원** (판매·경비·원가 모두)
6. 비율·기준값은 입력, 물량·금액은 수식
7. 과거 파일의 0 관찰을 현재 미응답·모름의 자동 0 처리로 재사용하지 않는다
8. 모델농장분석은 숨김 시트, 수식 연결하지 않는다

## 주의

  구조는 따르되 **수식은 우리가 검산한다.**
