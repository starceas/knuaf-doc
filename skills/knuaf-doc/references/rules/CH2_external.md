# Ⅱ. 외부환경분석 요구사항

적용 범위: 이 문서는 2020 특용작물 작성요령의 발췌·해석이다. 학교 원문 사실과 내부 해석·사례 관찰을 구분한다. 다른 전공에 이 목차·양식을 자동 적용하지 않는다. 현재 작성·검사 정책은 [thesis-level.md](../thesis-level.md)·[source-contract.md](../source-contract.md)를 따른다. 새 교수 지시는 별도 등록하며, 현행 금칙 게이트는 문서 해석만으로 면제하지 않는다.

출처: 학교 창업논문 작성요령 2020 PDF(sha256 `f60b58b7dcde86eab9f273dd50114ac296d009bd60abb940aaa866a54e866de2`) [양식 5] 이후 본문 양식에서 정리한 발췌·해석. 명시적 원문 항목의 발췌이며 내부 권고·보조 해석은 학교 의무가 아니다. 선배·참고 사례 관찰은 학교 의무가 아니다.

## 목차 충돌 주의

원문 [양식 4] 목차는 Ⅱ장을 4개 절로 제시한다.

    1. 농업환경분석 / 2. 시장환경분석 / 3. 모델농장분석 / 4. SWOT분석

그러나 본문 양식에서는 모델농장분석과 SWOT이 `Ⅲ-2. 영농목표 및 전략`의 하위(라·마)에 있다.
**같은 문서 안에서 배치가 충돌한다.** 원문 내부 충돌이며 교수 지시가 달라지면 그 지시를 따른다.
잠정 본문 양식(Ⅲ-2 하위)을 채택하되 프로필에 이유를 남긴다. 현행 특용작물 구조 검사와 다른 Ⅱ장 배치는 사유 메모만으로 통과시키지 않는다. 교수 지시는 새 출처로 등록해 대조한다.

## 1. 농업환경분석

### 가. 농장 개요

먼저 `표 1. 농장 종합 개요`를 배치한다. 항목: 농장명 / 경영주 / 농장위치(예정) / 가족사항 / 주요작목

**Ⅱ장 표는 셀 병합 구조가 있다.** 원형대로 재현한다(`F_format.md` F6, 원문 표 목록).
기상환경·재해·주요농산물 생산현황 표가 해당한다.

- 1) 농장명 — 이름을 짓게 된 배경이나 설명
- 2) 농장주
- 3) 농장위치(예정)
- 4) 주요작목
  - 가) 위치: 주소 + 간단한 지도 → `그림 1. 창농 예정 위치`
  - 나) 교통망 ※ 농장 방문안내 위주로 기술

#### 작성방법 (원문)
- **경영주 정의**: 창업하여 독립경영하면 졸업생이 경영주. 아버지 영농을 도우며 승계 예정이면 **아버지가 경영주**.
- **농장위치**: '외부에서 농장을 어떻게 찾아올 것인가' 관점으로 기술
- **가족사항**: 함께 영농에 참여하는 가족을 기입. **영농 참여율**을 함께 적는다.
  일일 활동시간 중 영농 시간 비율(예: 10시간 중 8시간이면 80%).
  가족 노동력 공급 가능량 계산의 기초자료다.

### 나. 지역적 조건

- 1) 기상환경 — 아래 표 필수
- 2) 농장의 지형 — 경사도, 농기계 진입 용이성, 산간지/중산간지/평야지
- 3) 토양조건 — 토양 종류, 비옥도, 토심
- 4) 수리조건 — 물 조달 방법(관정·댐·저수지 등)과 부족 여부
- 포장의 경지정리 상태 — 크기, 모양(보조 해석 항목). 원문 목차에는 5) 번호가 없으므로 새 번호를 학교 원문으로 주장하지 않는다.
- 6) 재해 — 아래 표 필수

#### 기상환경 표 (12개월 전체)
행: 평균기온(℃) / 최고기온(℃) / 최저기온(℃) / 강우량(mm) / 평균적설량(cm) /
최고적설량(cm) / 주된풍향 / 평균풍속(m/s) / 최대풍속(m/s)
열: 겨울(12·1·2월) 봄(3·4·5월) 여름(6·7·8월) 가을(9·10·11월) + 연평균
하단 필수 기재: 관측장소 / 최근 5개년 평균 기간 / 초상일(가장 빠른 첫서리) / 만상일(가장 늦은 늦서리)

#### 재해 표
열: 가장 자주 발생 / 자주 발생 / 가끔 발생
대상: 한발·홍수·태풍·공장폐수·공해가스·야생동물 등

#### 작성방법 (원문)
지역의 기상·지형·토양 조건이 **영농할 작목의 농작업 단계별 최적 재배여건과 맞는지** 설명한다.
단순 소개가 아니라 작물 생육조건과 대비해야 한다.

    예) 콩 파종은 평균기온 20℃ 이상이며 양평의 6월 평균기온은 21.4℃로 콩 재배에 적합하다.
    예) 토양은 사양토이고 pH 3.7이므로 적정 pH 6.5와 비교해 산성화되어 토양 개량이 필요하다.

### 다. 지리, 사회, 경제적 조건

- 1) 지리적 조건
  - 가) 교통 및 도로망 (주도로와 연결도로망)
  - 나) 차량 진입 용이성
  - 다) 주요 농산물 출하시장과의 거리 → 표(주요출하시장·거리·소요시간·비고)
- 2) 주요농산물 생산현황 → 표(순위·농산물명·생산규모·총매출액·주요출하시장 1·2순위)
- 3) 영농조직상태 및 주요 농산물 유통과정 → 표(작목명·영농조직·출하방법·주요출하선)
  ※ 영농조직은 작목반·영농조합법인 등을 기재하고 괄호에 참여농가수

#### 작성방법 (원문)
지리·사회·경제적 조건은 **농산물 유통·판매와 연결**해 작성한다.
도로 교통망은 농장에서 주요 시장까지 가는 경로를 기술한다.
출하시장·유통조직·출하방법을 적는 목적은 **기존 조직을 어떻게 활용할 수 있는지 판단**하기 위함이다.
