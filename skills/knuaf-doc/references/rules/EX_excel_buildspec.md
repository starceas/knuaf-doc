# 엑셀 시공 사양서 (하위 모델 실행용)

출처·성격: S0 보존 스냅숏의 옛 참고 엑셀 관찰을 바탕으로 한 내부 제작 기록이다. 학교 의무가 아니다. 과거 셀·수식·고정값을 현재 학생 입력으로 복제하지 않는다. 현행 `../excel-template.md`·`../thesis-level.md`·`../specialty-crops/finance-flow.md`·`../price-research-routes.md`를 우선한다.

아래 셀 지침은 옛 레거시 프로필 관찰·예시이며 실제 학과 템플릿을 재조립하는 명세가 아니다. 템플릿이 없을 때의 제한적 레거시 사용은 `../workflow-order.md`가 정한다. 현행 특용작물 재무표 전개기는 레거시 레이아웃을 거부한다. 값·연도·비율·0 처리·시트별 셀은 실제 정본과 대상 통합문서에서 재확인한다.

### 4.원리금상환계획

    B6  연도 | C6 융자금액 | D6:E6 원리금 상환액 | F6 연말융자잔액 | G6 비고
    D7  원금상환 | E7 이자
    B8  <창업연도>   C8 <융자액>   D8 <원금상환>   E8 <이자>   F8 =C8-D8
    B9  =B8+1        F9 =F8-D9   ← 잔액은 전년 잔액에서 차감

**거치기간 처리**: 거치 중인 해는 `D열(원금상환)=0`, `E열(이자)=융자액×금리`.
거치 종료 후 `D=융자액/상환기간`.

    D8 = =IF(B8-$B$8+1<=<거치년수>, 0, $C$8/<상환기간>)

      각 채널·등급마다 (수량=나항 참조, 매출액=수량×단가/1000)

**핵심**: 비율만 입력하고 물량·금액은 전부 수식. 단가는 절대참조(`$O$7`).

## 5. 계산 대조 참고 (현행 실행 계약 우선)

실제 재계산·출력 경로는 `../outputs.md`를 따른다. 단순 형식 변환은 재계산·독립 검토의 증거가 아니다.

재계산 후 `data_only=True`로 읽어 확인한다.

1. 수식오류 0건: `#REF!` `#DIV/0!` `#VALUE!` `#NAME?` `#N/A`
2. 자산 = 부채 + 자본 (13번 시트)
3. 기말현금 → 익년 기초현금 연결 (14번 시트)
4. 손익 순이익이 독립 십진 계산의 명시된 출력 단위·반올림 결과와 일치 (비율 오차 허용 금지)
5. 판매계획 채널 수량 합계 = 생산계획 생산량

하나라도 실패하면 원인을 찾아 고친다. **실패한 채로 완료 보고하지 마라.**

## 6. 레거시 경로의 제한
