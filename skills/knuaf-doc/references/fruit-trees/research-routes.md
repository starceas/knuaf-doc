# 과수전공 S01 양식 기반 리서치 경로 안내

- 최신성 경계: 2026-11-04 관찰 기준이며 오늘 최신성 확인 아님. KOSIS 두 과실표 원문 확인 외 세부 경로는 탐색 후보.
- S01 계약 및 지원 경계: 학교 과수 S01 「과수전공 논문양식 2026」 구조를 출발 기준으로 사용 (**Ⅱ-4 SWOT은 기준 위치**). 질문·문서계획·생산검산(kg/주/㎡)과 [본문 초안(글)](../major-body-draft.md) 작성은 지원한다. 서식 본문 파일·학교 재무 XLSX·재무 계산은 미지원(`unsupported_output`) 상태다. 과수 벤치마크 팩은 비어 있음(`empty_slot`).
- 기본 원칙: 선배 과수 논문 수치·재식거리·수량 상속 금지. 외부 통계는 비교 벤치마크이며 학생 계획값으로 자동 승격하지 않음.
- 자료 역할: 작성 규칙·지침은 형식(A)은 준수·검사하고 내용·구성(B)은 의도 확인 후 조정하는 기준, 선배 본문은 흐름·구성의 실제 적용 견본(형식 면제 근거 아님), 재무 엑셀은 시트·수식 구조의 정본이다. 선배 본문과 엑셀의 작성자가 같다고 가정하거나 견본끼리 숫자를 맞추지 않는다. 재무는 제공 엑셀이 기초이며 구조·수식을 보존하고 학생 입력값만 바꾼다. 과수 재무 미지원은 유지한다([전공 공통 원칙](../research-route-index.md)). 애매하면 A로 적용하며 형님이 풀어 준 때만 B로 처리한다. 낙농 문체 등 형님 고정 규칙은 유지한다.
- 공통 계약: [research-routing.md](../research-routing.md), [research-sources.md](../research-sources.md), [source-contract.md](../source-contract.md), [figure-research-routes.md](../figure-research-routes.md) 참조.

## 2. Ⅲ-5 생산량 계산 및 재고의 수학적 경계

1. **생산량 계산 (대안 관계, 합산 불가)**:
   - 주수 기준: `생산량(c,y) = 결실주수(c,y) × 주당수량(c,y)`
   - 면적 기준: `생산량(c,y) = 결실면적㎡(c,y) / 1000 × 10a당수량kg(c,y)`
   - 전체 면적(또는 전체 주수)을 결실 면적(또는 결실 주수)으로 대체하지 않는다. 결실하지 않는 유목(미과수)에 성목 단수를 적용하지 않는다.
2. **재고 논증 공식**:
   - `기말재고 = 기초재고 + 수확·유입 - 판매 - 손실 - 자가소비 - 가공·체험출고`
   - 등급변경이나 혼합 시 원물 수량이 이중계상되지 않도록 통제한다.

## 3. 실행 순서 및 빈 자료 처리

1. **실행 순서**: Ⅰ장 서론 → Ⅱ-1 입지·토양 실측 확인 → Ⅱ-2 KOSIS 과실표(`DT_1ET0292`, `DT_1ET0296`) 대조 → Ⅱ-4 SWOT(S01 기준, 의도한 배치 차이 허용) → Ⅲ-2 품종/대목 선택 → Ⅲ-5 결실주수 기반 생산량 산출 → Ⅲ-6 판로·단가 대조 → Ⅳ장 맺음말.
2. **빈 자료 처리**: KOSIS에 수록되지 않은 신소득 과수는 타 과종 수치를 복제하지 않는다. 지자체 농업기술센터 실증 자료를 직접 조사하여 비교 근거로 활용하되 한계를 명시하며, 자료 부재 시 해당 연도 생산 추정을 보류(Held)한다.
