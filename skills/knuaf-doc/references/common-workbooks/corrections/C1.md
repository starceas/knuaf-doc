### XR-04 — 농가소득·농업소득·영농잉여 기준 (교재 근거: silent)

| 선택지 | 결과 |
|---|---|
| A: (주산물 수입 + 부산물 수입) − 경영비 | 부산물 수입만큼 주산물 기준 영농잉여보다 커질 수 있다 |
| B: 주산물 수입 − 경영비 | 부산물 수입을 소득 기준에 넣지 않는다 |
| C: 조수입 − 생산비 또는 주산물 수입 − 생산비 | 생산비·경영비 구성 차이만큼 A/B와 달라진다 |

미결: 지표별 명칭, 부산물 포함 여부, 경영비/생산비 범위, C11 학교 행 매핑.

### XR-05 — 투자계획 계와 융자 (교재 근거: silent)

| 선택지 | 결과 |
|---|---|
| A: 계 = SUM(자부담:융자), 총투자액 해석 | 융자 증가분만큼 계도 증가한다 |
| B: 계 = SUM(자부담:보조), 부분 소계 해석 | 융자 증가에도 계가 변하지 않으므로 총자금과 별도 표시해야 한다 |

미결: 표 제목의 계가 총투자액인지 부분 소계인지.

### XR-06 — 고정자산·과수 감가상각 (교재 근거: partial)

교재는 감가상각대상금액 = 취득원가 − 잔존가치(물리 187쪽), 정액법
(취득원가−잔존가치)/내용연수(물리 190쪽), 법인세법 선택 문맥의 잔존가치 원칙
0원·정률법 5%(물리 189쪽)만 설명한다. 이 양식의 자산별 잔존율, 실제 내용연수,
과수 조성비 투입 시점, 학교 기준은 정하지 않는다.

| 선택지 | 결과 |
|---|---|
| A: 표시 셀이 잔존율이면 정액법 (취득원가−취득원가×표시 잔존율)/내용연수 + 누계 상한 | 입력이 10%이면 첫해 금액은 같을 수 있으나 이후 잔존율 변경·누계 상한에서 차이가 난다 |
| B: 학교가 자산별 고정 잔존율을 명시하면 고정률 적용 | 표시 셀의 의미를 별도로 정해야 한다 |
| C: 법인세법 선택 확인 시 해당 자산·방법에 한해 0원(정률법 5%)·신고 내용연수 | A/B와 연간 상각액·순장부금액·손익이 달라진다 |

미결: 학교 회계기준·세법 선택, 자산별 방법·잔존가치·내용연수, 과수 성숙/미성숙·
조성비 범위, 연도별 취득·상각 개시, 누계 상한 구현.

### XR-11 — 미지급 자가·가족노동의 현금흐름 (교재 근거: partial)

교재는 현금흐름표가 실제 현금을 수반한 거래만 선별한다는 일반 원칙(물리 370쪽)을
뒷받침한다. 자가노동 평가액의 농장 원가/소득 분류, 실제 지급 여부, 이 양식의
생산원가 구성은 정하지 않는다.

| 선택지 | 결과 |
|---|---|
| A: 자가노동이 실제 지급된 노동비이면 현재 식 유지 | 지급액은 현금지출에 반영된다 |
| B: 전액 미지급 평가액이면 현금지출에서 해당 평가액 차감 | 현금지출이 그만큼 낮아지고 순현금흐름은 높아진다 |
| C: 일부만 지급됐다면 미지급 부분만 차감 | 총액 일괄 차감은 현금지출을 과소계상한다 |

미결: 평가액의 지급 상태·포함 범위, 소득/생산원가에 평가액을 유지하는 학교 원칙.

## 검증 (로컬, 실제 파일)

실원본 결합 검증은 CI 테스트가 아닌 별도 로컬 통합 단계다. `python3 -m unittest tests.local_real_sources -v`로 X01·X02·SEO 원본의 명세 결합, 변이 거부, SEO 패치 영수증을 확인한다. `NOT_RUN`은 해당 원본이 없어 검증을 실행하지 못했다는 뜻이며 PASS로 집계하지 않는다.

`verify-c1`은 명세를 메모리에 적용해 (a) 관계별 부호 응답 벡터(N2), (b) 배제
프로브(N3: 같은 연도 열의 다른 참조 셀·의도된 원천 셀의 상하 인접 셀을 흔들어
모든 대상의 응답이 0인지 확인), (c) 분석기 차이(사라진/남은/신규 경고),
(d) 기준값 변화 목록을 산출한다. 동일 전제조건 함수가 재료화기·검증기를 공유한다.

- X01/X02/SEO: canonical PASS — 벡터 X01 46 / X02·SEO 42 전부 일치, 신규 분석기
  경고 0, 사라진 구조 후보는 정정된 R1/R2/R3/R4/R6(개시이월) 항목뿐.
- 돌연변이(전부 FAIL 확인): 연도 스왑(XR-19 C68↔C88), 오프바이원(XR-18 D30이
  C50 소계를 가리킴 — 필수 변이), 항 누락(XR-09), 부호 반전(XR-09), 이월 끊김
  (XR-22 H44=H20, X01만), 항 중복(XR-20).
- 기준값 변화: 교재 예시의 단순 입력(연도 동일 값)에서는 0 — 소유자 판독대로 결함이
  같은 값에 숨어 있었다. 연도별 다른 입력에서는 변한다.
