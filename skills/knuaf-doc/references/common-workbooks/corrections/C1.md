### XR-04 — 영농잉여 기준: 같은 양식의 계(총수입) 행 (decided)

결함은 '15.추정소득분석'의 잉여 블록뿐이다 — 행 5 주산물가액, 6 부산물가액, 7 계,
26 비용 계, 27 영농잉여, 28 영농잉여율. 12!C6·12!C26·2!C12는 이미 부산물을
포함하거나 다른 지표라 건드리지 않는다.

- X02, SEO: E27:I27 `=E5-E26` → `=E7-E26`; F28:I28 `=F27/F5` → `=F27/F7`
  (각 파일의 비율 단위 유지 — X01의 ×100 체계는 그대로).
- X01: E27:I27은 이미 `E7-E26`; E7 저장 상수 0을 `=SUM(E5,E6)`으로
  (F7:I7과 같은 식).
- 보류: E28 1년차 잉여율 저장값(3개 원본 모두 0).

근거: 교수 본인의 일반 양식 X01이 계(행 7)를 영농잉여 분자로 쓴다 — 같은 양식의
내부 일관성(소유자 지침: 다른 통합문서도 증거로 사용 가능). RDA 총수입(구 조수입)이
부산물 가액을 포함한다는 점(N 물리11/인쇄5, 물리13/인쇄7; R 물리9/인쇄5)은 보조

### XR-05 — 투자계획 계는 융자를 포함한 총액 (owner option A)

같은 '3.투자계획' 시트에서 1년차 행은 원본별로 다르다 — X01은 E19:E22가
`=SUM(F:H)`이고 E23은 저장값, X02는 E19:E23이 `=SUM(F:H)`이고 E24는
저장값, SEO는 E19·E21만 `=SUM(F:H)`이고 E20·E22·E23은 저장값이다(융자 포함
식인 행 기준). 후속 연도 행은 `=SUM(F:G)`(융자 누락) — 내부 불일치. 원예 원본·
특용 선배
통합문서 두 종 모두 동일하며, 선배들은 투자 전액을 융자 열 H에 넣어 계가 H를
포함해야만 의미가 있다.

- 후속 연도 계: X01/SEO E25:E28, X02 E26:E29 → 같은 행 `=SUM(F{r}:H{r})`.
- 보류: 1년차 저장 셀(X01 E23, X02 E24, SEO E20/E22/E23)은 바꾸지 않는다.
- 공공자료·교재 모두 이 열의 규칙을 정하지 않는다 — 소유자 결정(option A)이 근거다.

### XR-06 — 표시 잔존가격율 셀을 읽는 정액법 (rate link only, partial)

정한 부분: 연간 상각식 `=(취득가−취득가×0.1)/내용연수`의 하드코딩 0.1을 같은 열의
표시 잔존가격율 입력 셀로 바꾼다(예: X01 H12 = `(H8-H8*H9)/H10`). 근거: N
물리11/인쇄5 정액법; 교재 T 물리187/인쇄183 감가상각대상금액=취득원가−잔존가치,
물리190/인쇄186 연간=(취득원가−잔존가치)/내용연수, 누계는 취득원가−잔존가치를
넘지 않는다.

- 대상: '10. 감가상각비계획 ' 연간 상각 행(12/24/36/48/60) — X01 H열, X02 H·J열,
  SEO F·G·H열. 각 셀은 기존 정확한 식 `=(c8-c8*0.1)/c10`을 전제조건으로 한다.
- 보류: 누계 상한·내용연수 만료(누계 행 13/25/37/49/61은 있으나 상한은 MIN이
  필요해 평가기가 지원하지 않고, 만료는 개시 시점 근거가 없다), 잔존 항이 없는
  열(X01 D–F `=D8/D10` — 자산별 잔존가치 선택은 입력자 값). 잔존율 값·내용연수·
  상각 개시·성목/미성목 처리도 근거 부재로 입력자 값·보류다.
- 기준값 변화: X02 J9가 저장 0이라 J열 상각이 취득가/내용연수로 오른다 — 나머지는
  표시율 0.1과 같아 변화 없음.
- 한계(기록): 누계 상한·만료가 없어 사본은 내용연수와 무관하게 계획 기간 전체에
  같은 연간 상각을 표시한다.

### XR-11 — 미지급 자가 노동비의 현금흐름 제외 (owner option A)

가정(option A, 소유자 결정 2026-09-27): '8. 노무비계획' 자가 노동비(11!{y}12로
들어오는 ' 1. 급여')는 전액 미지급 평가액이다. 실제로 지급하는 노동은 — 가족에게
지급하는 경우를 포함해 — 고용 노동비로 입력해 현금지출로 남긴다. 이 가정이
거절되면 XR-11은 전부 HELD로 되돌린다.

- 정정: '14. 현금흐름계획' 당기총생산 원가(현금지출) X01 D17:H17, X02/SEO
  D18:H18 `='11. 생산원가계획'!{y}31-'11. 생산원가계획'!{y}21`에 같은 해
  `{y}12`를 추가 차감 (11 시트 연도 열 D..H ↔ C..G).
- 비용 항목 근거(지급 상태를 증명하지 않음): 11!C12 ' 1. 급여' = 8!H10 자가 노동비
  소계(자가+가족), 11!C15 ' 4. 잡급' = 8!H13 고용 노동비 계.
- 공공·교재 근거: 자가노동비는 평균 임금으로 평가한 기회비용이라 생산비에 속하고
  경영비(외부 구입분)가 아니다(N 물리12/인쇄6, 물리13/인쇄7); 현금흐름표는 실제
  현금 거래만 기록한다(T 물리370/인쇄366).
- 전제조건: 원본의 {y}12가 8 시트 자가 노동비 소계 행을 참조하지 않으면 그 원본은
  HELD.
- 후속(별도 작업): 인터뷰에서 자가·가족노동의 실제 지급 여부를 한 번 묻는다.
  지급분은 고용 노동비로 입력하므로 수식 변경 없이 현금지출에 남는다. 무응답·
  모름이면 option A.

## 한계

- XR-16/17은 구조적 확장(새 셀·행)이 필요해 v1에서 보류 — 필요한 결정은 위 표에 있다.

  전체에 같은 연간 상각을 표시한다(기록된 한계).
- XR-11은 option A 가정 아래에서만 유효하다 — 자가 노동비의 일부가 실제 지급된다면

  항목은 HELD로 되돌린다.

  15!E28 1년차 잉여율, 1년차 투자 저장 셀)은 입력자 값·보류다.
