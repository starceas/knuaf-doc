# 입력 의존성에 따른 진행

자료 계약은 [source-contract.md](source-contract.md), 제출 엑셀 템플릿 CLI 경로는
[excel-template.md](excel-template.md)를 따른다. 상세한 시트·계산 구조는 개발
환경에서만 `references/excel-submission.md`를 참고한다. 이 문서는
순서와 재검산 게이트만 정한다.

1. [intake-selection.md](intake-selection.md)에 따라 현재 작성물과 참고자료를 구분하고 작성 기준을 확인한다. 확인된 작업폴더의 정본·원답변·현재 절을 읽는다. 기존에 명확히 확인된 선택과 답변은 다시 묻지 않는다.
2. 현재 확인된 2020 공식 PDF(해시와 26쪽 물리 범위를 먼저 확인)의 1–5쪽 지침과 6쪽 이후 양식·예시를 분리해 등록한다. 다른 판본에는 이 분할을 자동 적용하지 않는다. 특용작물전공에서 서술 및 Ⅳ장 재무표 전개의 우선 기준은 이유림 선배논문(산약, `lee-yurim-exemplar-hwp`·`lee-yurim-exemplar-pdf`)이며([thesis-level.md](thesis-level.md), [specialty-crops/finance-flow.md](specialty-crops/finance-flow.md)), `kim-wonseop-exemplar-pdf`(선배논문, 지황)는 보조 참고로 유지한다(타 전공은 각 전공 선배 논문 플로우를 따른다). 이유림은 수준 기준이며 학생 사실·가격·수치·개인정보를 복제하지 않는다. `seo-minseo-finance-xlsx`는 다른 작성자의 사용자 제공 재무 템플릿으로 별도 등록한다.
3. [guideline-tracking.md](guideline-tracking.md)에 따라 원문 전체 항목 목록과 항목별 적용·검토 연결을 등록한다. 학교 규칙과 학생 계획의 적용 범위를 구분한다. 학교 원문이 없으면 목차·제출 판정만 보류한다.
4. 다음 작업의 필수 입력을 확인한다. 생산기술뿐 아니라 수취가격·판로·비용·투자·금리·상환조건도 재무 입력이다. 작성·검산 중 사용자 프로필이나 중요한 선택이 더 필요해지면 [mid-work-questions.md](mid-work-questions.md)의 추가 인터뷰로 해당 결정을 보완한다. 처음 인터뷰가 끝났다는 이유로 미정을 임의 확정하지 않는다.
5. 입력이 있는 조사·초안·자료 정리를 진행한다. 자료 부족이나 적자가 전체 작성 중단을 뜻하지 않는다. 출처는 공식 통계·공공자료·학술·연구기관·학교 자료·교재·작성자 직접 조사만 허용하며 기사·블로그·인터뷰 등 비공식 자료는 배제한다.
6. 절 작성 전 원답변·원문 발췌·사실 및 계산·적용 학교 규칙·현재 본문을 묶는다. [exemplar-quality.md](exemplar-quality.md)와 [thesis-level.md](thesis-level.md)의 해당 장 기준, [narrative-expansion.md](narrative-expansion.md)의 소절 중심 질문을 읽고 서술 설계를 만든 뒤 확장 초안을 쓴다. 본문에는 NPV·IRR·B/C·할인율·민감도를 일체 노출하지 않는다(전 전공 공통). 특용작물전공은 학과 엑셀 표(17시트) 산출 비율만 간결히 다루며, 타 전공은 해당 전공 선배 논문 및 교수 지시에 따른다. 그다음 사실·수치와 서술 구성의 프로필 적합성을 각각 대조한다. 확장된 본문과 함께 **표 제목, 그림 제목, 캡션, 표 아래 설명문, 각주, 요약표 셀**을 윤문 대상에 포함하여 [korean-polishing.md](korean-polishing.md)의 `humanize-korean`을 적용하고 윤문 기록(적용 범위, 전후 대조, 검증)을 남긴 뒤 출력 검수로 간다. 인터뷰 원답변 대비 변경률로 작문량을 제한하지 않는다. `gg.py bundle <폴더> --scope <절ID>`는 참조 목록을 제공하며 원문 파일 읽기를 대체하지 않는다.
7. 제출 XLSX 템플릿이 있으면 템플릿 복제 경로를 먼저 사용한다. 명시된 입력 셀만 비우고 형식·수식·병합·시트명을 보존한다. 조사·인터뷰로 확인한 값은 별도 쓰기 매핑과 셀별 근거를 붙여 `gg_excel_fill.py`로 새 사본에 채운다. 복제 때 보존한 연도·가격·비율은 현재 계획의 확정값이 아니다. 템플릿이 없을 때만 레거시 생성기를 제한적으로 사용한다.
8. 작성 후 기계검사와 원문 대조 내용검토를 별도로 한다. [narrative-expansion.md](narrative-expansion.md)의 단계 E에 따라 필요한 시각자료가 실제 본문에 들어갔는지, 생략한 경우 다른 설명으로 충분한지 검토한다. 학교 필수사항 준수와 설명 충분성을 각각 판정한다. 정직한 적자는 사업 위험으로 남기되 계산 오류는 고친다.
9. 입력·원본 해시가 변경되면 관련 계산·절·검토·출력만 다시 확인한다. 새 근거가 없는 반복 인터뷰로 돌아가지 않는다.
10. 검토본을 저장하고 경로·보완 항목·미실행 검사를 함께 안내한다.

작업 상태: 필요한 사용자 답변 / 필요한 근거 / 진행 가능을 구분한다. 모름·거부 항목을 임의 0으로 채우지 않는다. 지원하지 않는 재무 모델은 계획을 보존하고 지원 산식으로 억지 단순화하지 않는다.

## 질문 종료와 작성 시작

작목·상품, 지역, 신규/승계 여부와 현재 알려진 운영 조건을 묶을 수 있으면
그 프로필로 설명 가능한 본문부터 시작한다. 모름·없음·거부도 원답변으로
보존하며, Q1~Q8 전체 확정이나 모호성 0을 작성 조건으로 삼지 않는다.
작목 자체가 미정이면 작목 의존 계산만 보류하고 기존 자료·선택 기준 정리는
진행한다. 학생 화자와 내용 확장은 [narrative-expansion.md](narrative-expansion.md),
질문 표현 예시는 [interview-guide.md](interview-guide.md)가 소유한다.

질문은 현재 판단을 바꿀 필수 공백에만 사용한다. 이미 받은 모름·없음·거부를
다른 표현으로 되묻지 않는다. 미응답은 값이나 0으로 바꾸지 않는다.
같은 field ID의 값 요청은 개방 질문과 필요한 도움 제시를 합쳐 최대 두 번이며,
확인 질문이라는 이름으로 횟수 제한을 우회하지 않는다.
정정은 횟수 초과를 이유로 거부하지 않고 원답변과 이전 값을 보존해 새 개정으로
등록한다. 질문 재개는 새 근거·사용자 변경·명시적 재개 요청이 있을 때만 한다.

외부 근거 부족은 그 근거에 의존하는 계산·주장·출력만 보류한다.
조사값을 자동 승인된 가정으로 올리지 않는다. 사용자가 허용한 검토용 가정은
독자가 볼 수 있게 표시해 해당 시나리오를 계산할 수 있다.
저장·재개에서는 새 질문보다 현재 결정과 가능한 다음 작업을 먼저 복원한다.
작성 시작 조건은 그대로이고 다음 질문 선택은
[interview-guide.md](interview-guide.md)의 다음 질문 고르기를 따른다.

## 가격·물가 조사와 노무비 계획

특용·약용작물·생허브는 [price-research-routes.md](price-research-routes.md)의 공식 통계 경로와 동의어를 조사 출발점으로 사용한다. 조사는 공식 통계(KAMIS, KOSIS, 산림조합 등)로 좁히며, 쇼핑몰이나 업체 게시 판매가는 참고하지 않는다(출처 불가). 확인하지 못한 값은 임의 추정하지 않고 "확인 불가"로 남긴다.

매출(판매가격), 영농자재비, 경비, 노무비(고용임금) 모두 물가상승률을 반영한다. 특히 **노무비 계획이 가장 중요**하므로 일반 물가상승률과 임금 상승률은 반드시 분리하여 적용한다. 상승률 값은 임의 추정을 금지하며, 공식 통계(KOSIS 소비자물가조사, 농가 고용노동임금 등)에서 확보해 출처 ID와 기준연도를 명시한다.

첫 인터뷰에서 작목·상품 상태·등급·단위·지역·판로·작성 기준연도를 파악한 뒤 조사한다. 최신이라는 이유만으로 소매가격을 농가 수취가격에 대입하지 않는다. 조사값의 기간·판로·규격이 계획과 맞으면 근거를 등록해 연도·가격과 연결 계산을 갱신한다. 맞는 자료가 없으면 필요한 값만 학생에게 보충 질문한다. 모름·없음·거부로 답한 항목을 새 근거 없이 반복 질문하지 않는다.

한 가격을 바꾸면 평균가격, 등급·판로별 판매량, 매출, 원가·손익·현금흐름, 본문·요약 중 실제 의존 항목을 다시 계산한다. 과거 5개년 관측과 미래 판매계획을 구분하며, 과거 평균을 미래 확정가격으로 자동 승격하지 않는다. 직거래·중하품을 수매 상품가의 고정 비율로 산출하는 기존 수식도 근거 없는 경우 그대로 승인하지 않는다. `project.json` 변경과 입력 사본 해시, 재계산 산출물 해시, 현재 개정의 대조 기록을 연결한다.
