# 원예환경시스템전공 작성 계획 모듈 (hort_env_systems 0.1.0)

이 모듈은 공용 작성 계약의 `hort_env_systems` 바인딩을 사용한다. 원예 학생에게 필요한 질문, 선택형 문서 계획, 근거 사용 규칙, 전공 교재 엑셀 주의 목록을 **읽기 전용 계획**으로 보여 준다. 논문 본문, 학교 제출 XLSX, 재무 계산, 원본 채우기는 지원하지 않는다. 공용 출력 가드가 이 출력들을 파일 생성 전에 보류한다.

## 사용

1. 전공 바인딩: 원답변 출처가 있는 `common.major_id = hort_env_systems` 사실을 모듈 버전 `0.1.0`과 함께 `gg.py apply`로 정본에 기록한다. 작목명·시설 유형·표지로 전공을 추정하지 않는다.
2. `python3 scripts/gg.py major-plan <프로젝트>`는 공용 형식의 질문·문서·근거·재무 능력을 보여 준다.
3. `python3 scripts/gg_hort_plan.py --project <프로젝트>`는 원예 계획을 JSON으로 반환한다.
   - `questions`: 원예 질문 25개와, 필드별로 정본에 기록된 사실의 답변 상태(여섯 공용 상태)·기간·범위. 값은 출력하지 않고 충돌도 판정하지 않는다.
   - `document_plan`, `precedents`: 선택형 절 15개와 선배 전체논문 2편의 장·절·부록 위치(물리쪽·인쇄쪽·목차쪽을 따로 기록).
   - `workbook_references`: 정본 원천 중 전공 교재 엑셀과 해시가 같은 파일을 다시 해시해 확인한다. 기록 해시·실제 바이트·교재 해시가 모두 같을 때만 주의 목록을 준다. 경로 오류·프로젝트 밖 경로·읽기 실패·내용 변경은 주의 목록 없이 보류 사유를 준다.
   - `evidence_rules`, `finance`: 근거 사용 범위·주의문과 재무 미지원 사유.
   바인딩이 없거나 다른 전공이면 종료코드 2로 보류한다. 파일을 쓰지 않는다.

## 핵심 전제 목록

[premise-probes.md](premise-probes.md)는 공용 인터뷰가 원예 바인딩에서 우선 확인할 숨은 전제(면적 정의, 작기와 회계연도, 난방비, 내재해 기준, 용수·양액, 판매 단위, 모종 조달, 수율 근거, 자금 요건, 병행 사업)를 공용 형식으로 적는다. 각 전제는 원예 질문 field에 연결되고, 연결 field가 없으면 신설 제안으로만 표시한다. 질문 순서·횟수 규칙은 공용 인터뷰 층이 정한다.

## 전공 교재 엑셀

전공 폴더의 18시트 엑셀은 강의 담당 교수가 양식을 기준으로 수업에서 설명하는 교재다(역할 `professor_reference`, 근거는 사용자 진술). 셀의 작목·가격·면적은 수업 예시이며 학생 계획값이나 검증 수치가 아니다. 공용 17시트 좌표 지도와 호환되지 않는다(시트 구성·수식 배치가 다름). 교재 안의 불일치 20건을 두 상태로 나눈다.
- `confirmed_inconsistency`: 같은 대상·정의·기간을 가리키는 두 위치가 서로 반대임이 셀만으로 성립한다.
- `needs_confirmation`: 값 차이·단위 해석·결과에 영향 없는 참조 이탈처럼 작성 의도를 확인해야 한다.

주의 목록은 학생 계획을 검토할 체크리스트다. 교재를 고치는 안이 아니다. 18시트 입력칸 지도·수식 교정·재계산이 검증되기 전까지 재무 계산은 `unsupported`다.

## 자료와 권리

`profile.json`은 비공개 원천의 해시·쪽·셀 위치와 일반 안내만 담는다. 원문 문장·셀 값·학번은 싣지 않는다. 해시·위치 공개는 원문 재배포 권리 확인이 아니다. 선배 전체논문은 제목·이름만 식별값으로 둔다. 공식 자료(내재해 설계기준 고시와 별표, 내재해형 규격 운영현황, NCS 학습모듈)는 서지·해시·사용 범위만 둔다. 적설심·풍속·소득값 같은 수치는 사용 시점에 원문에서 직접 확인한다. RDA 소득자료 값은 조사 집단의 비교값이며 학생의 수량·가격·매출로 옮기지 않는다. 공용 팩 `rda.econ.2025`의 원예시설 내용연수 일부 행(원문 133–135쪽)은 원문에 없는 행 이름으로 추출되어 원예 근거로 쓰지 않는다.

재사용 등록부(`builtin-sources.json`)의 원예 항목은 교재 엑셀 하나만 `profile.json`을 구조 추출물로 연결한다. 선배 논문과 공식 자료는 해시 식별만 등록되어 있어 재파싱을 대신하지 않는다.
