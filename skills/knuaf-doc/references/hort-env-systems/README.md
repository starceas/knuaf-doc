# 원예환경시스템전공 작성 계획 모듈 (hort_env_systems 0.2.0)

이 모듈은 공용 작성 계약의 `hort_env_systems` 바인딩을 사용한다. 원예 학생에게 필요한 질문, 선택형 문서 계획, 근거 사용 규칙, 전공 교재 엑셀 주의 목록을 **읽기 전용 계획**으로 보여 준다. 0.2.0은 전용 18시트 출력 프로필 `hort_18_sheet_reconstructed_v1`을 선언한다 — 이 프로필과 전용 변환 영수증·후속 검증이 충족될 때만 전용 18시트 XLSX 출력이 허용된다. 일반 능력 계약의 재무(`capabilities.finance`)는 계속 `unsupported`이며, 논문 본문 초안(글)을 제외한 서식 본문 파일, 학교 제출 XLSX, 재무 계산, 원본 채우기는 지원하지 않는다. 해당 파일·계산 요청은 공용 출력 가드에서 `unsupported_output`으로 보류한다. 조건부 전용 18시트 출력은 기존 경계를 따른다.
유효한 전공 바인딩이 있으면 [전공별 본문 초안(글)](../major-body-draft.md)을 장별로 작성할 수 있다. 원예 학교 작성요령은 등록되어 있지 않으며, 교수님이 틀 기준으로 지정한 HT2를 형식 기준(A)에 따라 따르고 HT1과 그 밖의 선배 논문은 내용·구성 참고(B)로만 사용한다. 작성요령이 등록되면 작성요령을 우선한다. 학생에게는 “학교 작성요령 미등록, 교수 지정 기준 HT2 사용”이라고 알린다. [형님 진술 2026-11-06 — 교수 지정 틀 기준, 해시로 HT2 확인]

## 사용

1. 전공 바인딩: 원답변 출처가 있는 `common.major_id = hort_env_systems` 사실을 모듈 버전 `0.2.0`과 함께 `gg.py apply`로 정본에 기록한다. 작목명·시설 유형·표지로 전공을 추정하지 않는다.
2. `python3 scripts/gg.py major-plan <프로젝트>`는 공용 형식의 질문·문서·근거·재무 능력을 보여 준다.
3. `python3 scripts/gg_hort_plan.py --project <프로젝트>`는 원예 계획을 JSON으로 반환한다.
   - `questions`: 원예 질문 25개와, 필드별로 정본에 기록된 사실의 답변 상태(여섯 공용 상태)·기간·범위. 값은 출력하지 않고 충돌도 판정하지 않는다.
   - `document_plan`, `precedents`: 선택형 절 15개와 선배 전체논문 2편의 장·절·부록 위치(물리쪽·인쇄쪽·목차쪽을 따로 기록). 학교 구조 검사(`school_structure`)는 이 선배 논문(HT1·HT2) 프로필 계약에 따라 Ⅲ-4 위치의 SWOT 분석을 검사하며, 특용작물의 6장 목차나 Ⅲ-2-마 위치를 강제하지 않는다.
   - `workbook_references`: 정본 원천 중 전공 교재 엑셀과 해시가 같은 파일을 다시 해시해 확인한다. 기록 해시·실제 바이트·교재 해시가 모두 같을 때만 주의 목록을 준다. 경로 오류·프로젝트 밖 경로·읽기 실패·내용 변경은 주의 목록 없이 보류 사유를 준다.
   - `evidence_rules`, `finance`: 근거 사용 범위·주의문과 재무 미지원 사유.
   바인딩이 없거나 다른 전공이면 종료코드 2로 보류한다. 파일을 쓰지 않는다.

## 작목에 공통으로 적용하는 작성 규칙과 흐름

선배 논문에서 재사용할 것은 **특정 작목의 내용이나 참고논문 목록이 아니라 장의 역할·전개 순서·근거 제시 방식**이다. 아래는 제공된 두 선배 논문의 공통 흐름과 서로 다른 배치를 대조해 일반화한 작성·검토 안내다. 작목·품종·지역·설비 모델·가격·수율·계수·문장을 복사하지 않는다. 학교 작성요령·교수 지시가 있으면 그 출처를 우선 확인하고, 선배의 관찰을 새 의무 규정으로 만들지 않는다.

자료는 작성자가 아니라 다음 **세 가지 역할**로 구분한다. 같은 사람이 작성했을 수도, 서로 다른 사람이 작성했을 수도 있으므로 동일 사업의 자료라고 가정하지 않는다.

| 자료 | 작성 시 역할 |
|---|---|
| 논문 작성 규칙·지침 파일 | 작성의 출발점. 아래 A 형식 규칙은 지키고 검사하며, B 내용·구성 규칙은 사업에 맞게 조정하는 기준선 |
| 선배 논문 본문 | 지침을 실제 적용한 흐름·구성 견본. B의 조정 범위를 참고하되 A를 어겨도 된다는 근거로 쓰지 않으며 내용·숫자·작목·문장을 복사하지 않음 |
| 재무 엑셀 | **양식 자체가 정본**: 시트·수식 구조를 보존. 기존 내용·숫자는 학생 계획의 근거가 아니며 허용된 입력 셀의 값을 학생의 검증된 값으로 바꿈 |

재무는 이 기준 엑셀이 기초다. **엑셀 수식은 건드리지 않는다.** 논문과 엑셀의 예시 숫자를 서로 맞추거나 그 차이를 충돌로 보고하지 않으며, 논문의 예시 숫자에 맞추기 위해 엑셀 값이나 수식을 바꾸지 않는다.

지침의 규칙은 다음 두 종류로 나누어 검토한다. **모든 지침 이탈을 알림만으로 처리하지 않는다.**

| 구분 | 범위 | 차이가 있을 때 |
|---|---|---|
| **A. 형식 규칙** | 그림·표 제목 위치와 번호, 사진·자료 출처 표기법, 참고문헌 양식, 띄어쓰기·줄바꿈·글꼴·글자 크기, 쪽번호, 단위·숫자 표기, 목차 형식 | 반드시 지키는 검사 대상. 다르면 고치도록 요구하며 ‘의도면 OK’로 넘기지 않음 |
| **B. 내용·구성 규칙** | 장·절에서 무엇을 얼마나 쓸지, 하위 항목 순서, 분량, 예시 문장 | 사업에 맞게 조정 가능. 다르면 **“규칙과 다름 — 의도면 OK”**로 알리고 의도를 확인 |

읽는 사람이 **“양식이 틀렸다”**고 볼 차이는 A, **“내용 구성이 다르다”**고 볼 차이는 B다. 애매하면 A로 지키며 사용자가 명시적으로 풀어 줄 때만 B로 다룬다. 선배 견본만으로 A의 예외를 만들지 않는다.

사용자 고정 규칙(엑셀 수식 유지·엑셀 기준 재무 작성·전공별로 명시된 고정 문체 등)은 그대로 유지한다. 이 분류는 작성·검토 안내이며 모든 A 항목의 자동 검사가 구현됐거나 기존 실행 검사·출력 가드가 변경됐다는 뜻은 아니다.

### 장별 역할과 연결

| 순서 | 다룰 내용 | 다음 부분으로 넘길 판단 |
|---|---|---|
| 앞부분 | 표지·제출·인준, 목차·요약·표목차·그림목차. 요약은 사업개요·목표·주요 계획과 본문의 확정 내용을 일치시킴 | 제출일·졸업일·인준 상태를 학생별로 확인. 본문·재무가 바뀌면 요약과 목차도 다시 대조 |
| Ⅰ 머리말 | 영농 동기·사업 목적·대상 사업을 선택한 이유·계획의 범위 | 왜 이 사업을 계획하는지 설명하되 시장성·기술성은 뒤 장의 근거로 이어짐 |
| Ⅱ 농장현황 | 농장 개요, 생산품목의 특성, 생산기술·재배방법, 장해·병해충과 대응 | 현재 보유 사실과 도입 예정 계획을 구분하고, 생산에 필요한 조건을 환경분석·시설계획에 넘김 |
| Ⅲ 영농환경 분석 | 내부 역량·재무능력 → 외부 환경·시장·정책·지역 여건 → 모델농장 비교 → SWOT 및 대응전략 | 앞서 제시한 근거에서 강점·약점·기회·위협을 도출. 비교 농장의 조건 차이와 학생 농장에 적용할 점을 설명 |
| Ⅳ 농장비전 및 영농목표 | 비전 → 기간별 목표 → 경영전략(생산·품질·자재·노무·자금·판매·고객관리 등) | 분석 결과가 목표·전략 선택의 이유가 되어야 함. 목표의 기간·단위·규모는 Ⅴ장과 맞춤 |
| Ⅴ 영농계획수립 | 투자·자금조달·상환, 시설·설비, 생산·작부 일정, 원가·재무, 판매·마케팅, 교육·봉사를 구체화 | 목표를 일정·수량·금액·담당 실행으로 연결. 시설 규모→생산능력→판매량→비용·자금 흐름 사이의 일관성을 확인 |
| Ⅵ 맺음말 | 계획의 핵심·실현 조건·남은 위험과 대응·실행 의지 | 앞 장에 없는 새 실적이나 수익을 추가하지 않고 계획과 확인된 사실을 구분 |
| 후미·부록 | 참고문헌, 감사의 글·동의서 등 해당 양식의 후미, 재무 부록 | 학생 본인의 본문 인용과 참고문헌을 확인하고, 동일 사업의 본문 요약 수치를 기준 재무 엑셀의 기간·단위·합계에 맞춤. 서로 다른 작성자의 견본끼리 숫자를 대조하지 않음 |

장 순서와 **작성 작업 순서**는 구분한다. 공통 재무 게이트를 먼저 확인하고, 학생 본인의 기준 재무 엑셀과 계획·근거를 연결하면서 관련 절을 작성한다. 엑셀의 수식은 보존하고 허용된 입력값만 바꾸며, 본문 재무 설명은 그 엑셀을 기초로 쓴다. 본문·재무가 바뀌면 요약·목차·표/그림목차를 갱신한다. 위 순서가 재무 확인 전 본문부터 작성하라는 뜻은 아니다.

Ⅴ장의 하위 절 배열은 선례 사이에도 다르다. 투자→시설→생산→원가→마케팅→교육·봉사 흐름을 기준 틀과 대조하되, 생산·작부를 시설보다 앞에 놓거나 재무를 부록으로 연결한 관찰도 있다. **어느 배치든 같은 사업의 시설·생산·판매·원가·자금이 이어져야 한다.** 채택한 학교 틀·교수 지시에 맞춰 절을 배치하고, 특정 작목의 절 배열을 모든 작목의 의무 순서로 만들지 않는다.

### 절 안에서 근거를 제시하는 흐름

1. **조건과 판단 대상을 먼저 쓴다.** 대상 시설·면적·생육단계·기간·지역·단위를 밝혀 무엇을 결정하는 절인지 설명한다.
2. **자료의 출처와 적용 범위를 밝힌다.** 학교 교재·공식 통계·설계기준·실측·견적 등을 구분하고, 자료의 연도·쪽/표·지역·규모가 학생 계획과 맞는지 확인한다. 외부 평균이나 선배 사례는 학생의 실적이 아니다.
3. **산출·비교 과정을 보여 준다.** 입력 근거→계산 또는 대안 비교→결과→선택 이유를 연결한다. 프로그램과 직접 계산이 다르면 입력 조건·계수·단위 차이부터 확인하며 유리한 값만 고르지 않는다.
4. **실행 계획과 한계로 닫는다.** 선택 결과가 시설·생산·비용·판매 계획의 어느 부분에 반영되는지 설명한다. 대체 지역·대체 자료·미확인 가정은 적용 이유와 한계를 남긴다.

### 환경설계의 근거·단위 확인

| 검토 묶음 | 작목과 무관하게 확인할 연결 |
|---|---|
| 난방 | 시설 치수·표면적 → 설계내·외기온과 지역/기간·위험수준 → 피복·보온 조건과 계수 출처 → 최대난방부하 → 배관 손실·보정·안전계수 → 선택 기기 용량. 부하와 기기 용량을 구분 |
| 용수 | 해당 작목·생육단계의 필요수량 근거 → 적용 재배면적 → 순용수량 → 관개효율을 고려한 조(총)용수량 → 여유·저장 조건 → 탱크 용량. 일일 소요량과 저장용량을 구분 |
| 설비·운영비 | 설비의 필요성·규격·용량 근거를 투자비와 운영비에 연결. 설계 용량만으로 연간 사용량이 입증되는 것은 아님 |
| 환산·검토 | 부지/시설/재배면적, 면적당/농장 전체, 원/천 원, 시간당/일별/연간을 구분. 같은 표·본문·부록이 같은 단위·기간·규모를 가리키는지 확인 |

이 목록은 계산 엔진이나 전문 설계 검증을 대신하지 않는다. 계수와 기후값은 해당 공식 기준·교재의 판·쪽에서 다시 확인하고, 적용하지 않는 설비나 방식은 학생 계획에 맞춰 해당 여부를 판단한다. 특정 설비·재배법·작목 수치를 공통 기본값으로 두지 않는다. 질문 순서·횟수는 공용 인터뷰 계약을 유지한다.

### 표·그림과 문체

- **표**는 비교·목표·계산 입력/결과·계획 수치를 정리하는 데 쓴다. 제목·단위·기간·행/열의 대상을 명확히 하고 본문에서 핵심 차이와 선택 이유를 해석한다. 표를 붙인 것만으로 분석을 마쳤다고 보지 않는다.
- **그림·사진·도면**은 입지·배치·구조·계산 방법·설비를 이해시키는 근거로 쓴다. 본문 설명과 연결하고 번호·제목·본문 참조·목차를 대조한다. 의미 없이 장식으로 넣거나 선배 그림을 재사용 권리 확인 없이 복사하지 않는다.
- 외부 출처는 현행 공통 정책대로 제목 끝에 표시하며, 자체 작성·산출·촬영의 출처 표시는 생략하고 설명은 `주 :`로 구분한다. 선배가 표 아래 출처를 쓰거나 자체 촬영 출처를 붙였더라도 그대로 정책으로 채택하지 않는다.
- 머리말·맺음말의 개인 동기와 기술·분석 본문의 설명을 구분한다. 공통 `SKILL.md`의 본인/주어 생략 원칙을 따르고 사실·관측·목표·가정·계산을 구분한다. 선례의 경어체·평서체 혼재를 단일 의무 문체로 만들지 않으며, 확정한 문체는 일관되게 유지한다.
- 앞부분/본문 쪽번호 체계와 표지·제출·인준면 구성은 채택한 양식을 확인한다. 선배 PDF만으로 글꼴·여백·줄간격·분량의 학교 의무 수치를 새로 만들지 않는다. 실제 출력·한글 마무리·교수 확인은 기존 경계를 유지한다.

이 표는 기존 공통 정책을 소비하는 문서 경로이며 새로운 조사 상태 스키마·GUI 동작·자동 조사 기능을 정의하지 않는다.

### 적용 범위와 구현 경계

기존 `profile.json`의 장·절·부록 위치와 위 작성 흐름을 함께 읽는다. 생산원가·교육봉사·후미의 일부 위치는 이미 등록돼 있으며, 새 참고논문이나 작목별 재배 내용을 추가하는 보강이 아니다. 실행 계획은 여전히 HT1·HT2와 선택형 15개 노드이며 앞부분·후미 일부가 별도 노드가 아니고 마케팅이 원가보다 먼저 나열된다. 이 안내는 사람이 빠짐을 대조하기 위한 것이지 실행 노드·자동 검사·출력 능력을 바꾼 것이 아니다.

## 전공 교재 엑셀

전공 폴더의 18시트 엑셀은 강의 담당 교수가 양식을 기준으로 수업에서 설명하는 교재이며 **시트·수식 구조가 재무 양식의 정본**이다(기계 역할 `professor_reference`, 근거는 사용자 진술). 셀의 작목·가격·면적 등 기존 내용은 학생 계획값이나 검증 수치가 아니며 허용된 입력값만 학생 값으로 바꾼다. 공용 17시트 좌표 지도와 호환되지 않는다(시트 구성·수식 배치가 다름). 기존 교재 내부 주의 목록 20건은 아래 두 상태로 기록되어 있으나, 예시 내용의 일치를 요구하거나 정본 양식·수식 구조를 변경하는 지시로 사용하지 않는다.
- `confirmed_inconsistency`: 같은 대상·정의·기간을 가리키는 두 위치가 서로 반대임이 셀만으로 성립한다.
- `needs_confirmation`: 값 차이·단위 해석·결과에 영향 없는 참조 이탈처럼 작성 의도를 확인해야 한다.

위 상태는 **한 교재 내부**의 동일 대상·정의·기간에 대한 기존 주의 목록이지, 서로 다른 작성자의 논문·엑셀 견본 사이 숫자를 비교한 판정이 아니다. 견본의 값 차이만으로 충돌이나 오류를 만들지 않으며, 이 목록을 근거로 교재 또는 학생 엑셀의 수식을 고치지 않는다.

주의 목록은 학생 계획을 검토할 체크리스트다. 교재를 고치는 안이 아니다. 모듈 0.2.0은 전용 `hort_18_sheet_reconstructed_v1` 출력 프로필만 선언한다. 공용 `capabilities.finance`는 `unsupported`이며, 18시트 출력에는 전용 변환 영수증과 후속 검증이 필요하다. 0.1.0 정본은 원답변을 보존하고 `common.major_id`를 새 revision에서 명시 재바인딩해야 한다. 이전 계획 검토는 무효다. 재구성본의 변경은 공공기관 자료·학교 교재·선배 논문·교재 엑셀 중 하나 이상의 쪽·표 근거로 기록되어 있어(변환 지도 415묶음 전수 감사, 근거 부족 0) 수업·제출에 사용할 수 있다. 예외 1묶음: 단위·규격 환산 근거 31키는 공개 자료가 아니라 학생 견적·규격서로 채우는 입력 계약으로 유지하기로 사용자가 결정했다. 학생별 사실과 수치의 검증은 계속 필요하다.

자재 견적은 품목별 기준면적을 반드시 입력한다. 품목 단위 견적은 학생이 10a(1,000㎡) 기준으로 환산해 입력한다.

## 18시트 재무 입력 계약 (물가·임금·견적·출처)

원예환경시스템 18시트 재무 파라미터는 엄격한 출처 및 가격 계약을 따른다:
- **연간 상승률 (자재·경비 등 55키)**: 임의 비율(자유 RATIO) 입력 불가. PR-2 공통 공식 통계 계약(`price_contract: "series:general"`)으로만 정해진다. `price_assumption`(공식 출처 ID `source_id`, 기준연도 `base_year`, 단위 `unit`, 관측 `observation`, 선언 r)을 필수로 요구하며 `gg_price_assumptions` 공개 함수로 검증된다. 실제 셀 적용값은 항상 확정 관측 수열의 끝점 CAGR(연평균 변화율)로 대체된다.
- **학생 단가·견적 (300키)**: 연간 상승률과 분리된 `source:quote` 출처 계약으로 다루어지며, 출력 라벨은 출처 레코드의 `source`("학생 견적") 또는 `source_type="author_survey"`("작성자 직접 조사")로 명시 표시된다.
- **근거 요약 필드 (`cost.overhead.source_summary`, `cost.labor.wage_evidence_summary` 등 5키)**: 요약 셀은 승인된 공식 수열의 식별·관측기간·계산값(`통계명[source_id] 시작~끝년 관측 연평균 ±x.xx%`) 또는 고정 학생 표시("학생 견적" / "작성자 직접 조사")로 자동 생성된다. 직접 `source.source` 문구는 출력되지 않지만, 학생이 선언한 수열의 통계명·품목명·id는 요약 셀에 표시될 수 있다(상승률 값은 공식 수열 CAGR로만 결정). 원예 요약 사실이 상승률과 같은 공식 출처를 참조하면 거부되므로 요약 사실에는 별도 "학생 견적/작성자 직접 조사" 출처를 붙인다.
- **출처 허용 목록 및 신뢰 등급 제한 (`_check_fact_sources`)**: 근거 출처의 `kind`/`source_type`은 사전에 정의된 유한한 7개 허용 쌍(`stat`/`official_stat`, `public_data`/`official_public`, `academic`/`academic_paper`, `research_report`/`institution_report`, `school_material`/`official_school`, `textbook`/`formal_textbook`, `interview`/`author_survey`)만 인정된다. `interview`는 `author_survey`(또는 `source="작성자 직접 조사"`)만 허용되며 일반 타인 인터뷰나 외부 출처(`external_*`)는 차단된다. 신뢰 등급(`grade`)은 정수 1 또는 2만 허용되며, 정책 금지값(3, 4)은 물론 문자열·전각·공백 변형(`"３"`, `" 3 "`, `"3"`)이나 불리언·실수 등 비정규형은 정규화 없이 명시 거부된다.
- **생산 증가율 예외**: `sales.y2~y5.growth_rate`는 가격·임금 물가상승률이 아니라 **전년 대비 생산 증가율(생산량 스케일링)**이므로 물가 통계 수열 계약(`price_contract`) 대상이 아니며 기존 동작을 유지한다.

## 자료와 권리

`profile.json`은 비공개 원천의 해시·쪽·셀 위치와 일반 안내만 담는다. 원문 문장·셀 값·학번은 싣지 않는다. 해시·위치 공개는 원문 재배포 권리 확인이 아니다. 선배 전체논문은 제목·이름만 식별값으로 둔다. 공식 자료(내재해 설계기준 고시와 별표, 내재해형 규격 운영현황, NCS 학습모듈)는 서지·해시·사용 범위만 둔다. 적설심·풍속·소득값 같은 수치는 사용 시점에 원문에서 직접 확인한다. RDA 소득자료 값은 조사 집단의 비교값이며 학생의 수량·가격·매출로 옮기지 않는다. 공용 팩 `rda.econ.2025`의 원예시설 내용연수 일부 행(원문 133–135쪽)은 원문에 없는 행 이름으로 추출되어 원예 근거로 쓰지 않는다.

재사용 등록부(`builtin-sources.json`)의 원예 항목은 교재 엑셀 하나만 `profile.json`을 구조 추출물로 연결한다. 선배 논문과 공식 자료는 해시 식별만 등록되어 있어 재파싱을 대신하지 않는다.
