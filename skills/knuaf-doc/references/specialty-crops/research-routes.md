# 특용작물전공 논문 흐름 기반 리서치 경로 안내

- 최신성 경계: 2026-11-04 관찰 기준이며 오늘 최신성 확인 아님. 미확인 통계·자료는 탐색 후보.
- 기본 원칙: 선배 논문 수치·재배법 상속 금지. 외부 통계는 비교 벤치마크이며 학생 계획값으로 자동 승격하지 않음.
- 자료 역할: 작성 규칙·지침은 형식(A)은 준수·검사하고 내용·구성(B)은 의도 확인 후 조정하는 기준, 선배 본문은 흐름·구성의 실제 적용 견본(형식 면제 근거 아님), 재무 엑셀은 시트·수식 구조의 정본이다. 선배 본문과 엑셀의 작성자가 같다고 가정하거나 견본끼리 숫자를 맞추지 않는다. 재무는 제공 엑셀이 기초이며 구조·수식을 보존하고 학생 입력값만 바꾼다([전공 공통 원칙](../research-route-index.md)). 애매하면 A로 적용하며 형님이 풀어 준 때만 B로 처리한다. 낙농 문체 등 형님 고정 규칙은 유지한다.
- 공통 계약:
  - 리서치 원칙: [research-routing.md](../research-routing.md)
  - 공통 기관 메뉴: [research-sources.md](../research-sources.md)
  - 출처 등록 계약: [source-contract.md](../source-contract.md)
  - 가격 계약: [price-research-routes.md](../price-research-routes.md)

## 2. Ⅱ-2 품목별 3대 분기 및 탐색 절차

1. **일반 특용작물 (약용·유료·특수작물)**:
   - 생산·면적: 농림축산식품부 [2024 특용작물 생산실적](https://www.mafra.go.kr/bbs/home/795/575880/artclView.do) (114019, 11-04 원문 확인).
     - '품목별 생산실적' 인쇄 19쪽, '시도별·품목별' 25쪽 이후.
     - 약용작물은 건조 후 중량 기준이므로 생근 환산 시 수율 근거 명시 필요.
   - 가격·유통: [aT KAMIS 농수산유통정보](https://www.kamis.or.kr) 기간별 도소매 화면(11-04 기본 쌀 화면 확인, 개별 품목 탐색 후보) 및 경락가격(탐색 후보).
     - 도매가격은 중도매인 판매가격이며 농가수취가격과 다름 (기본 쌀 값 전용 금지).
2. **인삼 분기 (특용작물 생산실적 제외 품목)**:
   - 특용작물 생산실적에는 인삼이 제외되어 있으므로 0으로 처리하지 않음.
   - 농림축산식품부 『인삼통계자료집』 원문을 별도 탐색하여 면적·생산량 확보.
3. **임산물 분기 (농림 통계 조사범위 대조)**:
   - 특정 품목을 임산물로 선분류하지 않고, 원통계(농식품부 특용 생산실적 vs 산림청 임산물생산조사)의 수록 품목, 재배지(경작지/임야), 조사범위를 먼저 대조한다.
   - 산림청 [산림임업통계포털](https://kfss.forest.go.kr) 『임산물생산조사』 및 [산림조합](https://www.forestinfo.or.kr) 가격망은 해당 품목·지역의 조사 범위가 부합할 때 탐색 후보로 사용한다.

## 3. Ⅲ-5 가공·판매 법적 규제 탐색 절차

- 약용작물의 식품 원료 사용 여부는 단정하지 않고 탐색 절차를 거친다.
- 식약처 [식품안전나라](https://www.foodsafetykorea.go.kr) 식품공전 '식품에 사용할 수 있는 원료' 목록 조회.
- 사용 가능 부위(뿌리, 잎, 줄기 등) 및 제한적 사용 조건(배합 비율 등) 개별 고시 확인.
- 정확한 종·학명, 사용 부위, 용도별로 식품공전 허용 여부와 약사법 규격한약재 해당 여부를 각각 독립적으로 확인한다. 식품 원료 목록 미확인 자체를 약재 분류의 근거로 삼지 않으며, 허용 조건이 미확인된 용도의 판매 계획은 보류한다.

## 4. 실행 순서 및 빈 자료 처리

1. **실행 순서**:
   - `1단계`: Ⅰ장 동기 및 승계 사실 확인.
   - `2단계`: Ⅱ장 환경 및 품목 분기(일반특용/인삼/임산물) 확인.
   - `3단계`: Ⅲ장 작업력 수립 및 식품원료 법적 고시 탐색.
   - `4단계`: Ⅳ장 재무 검증 ([finance-flow.md](finance-flow.md) 및 [price-research-routes.md](../price-research-routes.md) 계약 준수).
   - `5단계`: Ⅴ장 종합 위험 분석 및 Ⅵ장 참고문헌 대조.
2. **빈 자료 (Data Absence) 처리**:
   - 공식 통계 부재 시 타 작목 수치 복제나 0원 처리를 금지한다.
   - 농업기술센터 실증 자료, 선진 농가 실거래 장부 등 작성자 직접 조사로 대체하되 모집단 한계를 명시한다.
   - 직접 조사 근거도 없는 경우 해당 세부 분석을 보류(Held)한다.
