# 학명·문헌 인용 표기 (citation-scientific-name)

작성요령 2쪽이 정한 학명 표기와 본문 인용 표기다. 고정 발췌는 [rules/F_format.md](rules/F_format.md) F2(학명)·F3(본문 인용)에 있고, 기계 대조 항목은 `guideline-inventory.json`의 OG-019~OG-022(p2)다. 이 문서는 그 규칙을 쓰는 방법과 **자동 검사 범위**를 적는다.

> **원문 발췌와 다른 점 (형님 결정 5-A)**: F_format.md F2-01·F2-02의 예시는 명명자를 가상 인명 `Hong`으로 적었고(F_format.md 자신이 "가상 인명"이라고 밝힌다), 학교 원문 2쪽 예시는 `Nakai`다. 발췌는 고정이므로 고치지 않는다. 실제 원고에는 F_format의 예시 인명을 그대로 쓰지 말고, 인용하는 문헌의 실제 명명자를 쓴다.

## 1. 학명

작성요령 2쪽 원문:

> (1) 작물명은 처음 나오는 것에 한하여 학명을 기재하며, <예> Angelica gigas Nakai / 두 번째부터는 속명을 약자로 기재한다. <예> A. gigas Nakai / 학명은 속명과 종명은 이탤릭체로, 명명자 및 var. 등은 로마체로 쓴다.

- **첫 등장**: 속명 + 종명 + 명명자를 모두 쓴다. 예: *Angelica gigas* Nakai
- **두 번째부터**: 속명을 첫 글자와 마침표로 줄인다. 예: *A. gigas* Nakai
- **기울임 범위**: 속명·종명만 기울임. **명명자(Nakai, L., (L.) Merr. 등)와 var.·subsp.·f.·cv.는 로마체.**
- **(일반 관례 — 학교 원문 아님)** 품종명(cv.)은 작은따옴표로 쓰고 로마체로 둔다. 예: *Cornus officinalis* 'Big Apple'. 원문은 cv.가 로마체라는 것까지만 말하고 작은따옴표는 정하지 않았다.
- **(일반 관례 — 학교 원문 아님)** 같은 문서 안에서 속이 바뀌면 다시 전체 학명으로 쓰고, 약자는 그 문서 안에서만 유효하다고 본다. 원문은 "두 번째부터 속명을 약자로"까지만 정했다.
- 원문은 작물명이 처음 나올 때 학명을 적으라고 한다. **학명을 생략해도 되는지는 이 문서가 정하지 않는다 — 교수 확인 사항이다.** 학명을 쓰는 이상 위 순서를 지킨다.

### 원고에 쓰는 방법

- 마크다운 본문에는 기울임을 `*속명 종명*`으로 표시한다. 예: `*Angelica gigas* Nakai`, `*A. gigas* Nakai`. 별표를 명명자까지 감싸지 않는다.
- DOCX 생성기는 `scripts/build_docx.py`의 `runs()`가 별표 구간을 기울임으로 내보낸다. 별표 없이 "속명 종명"만 쓴 경우에도 뒤에 대문자로 시작하는 단어(명명자 등)나 `var.`·`subsp.`·`f.`·`ex`·`×`가 붙어 있으면 학명으로 보고 자동으로 기울인다(`gg_document.SCI`). 이 판정은 뒤 단어가 대문자이기만 하면 걸리므로(예: 다음 문장 첫 단어) 넓게 잡힌다 — **명명자 없이 속명·종명만 쓰고 뒤에 대문자 단어가 오지 않으면** 자동 기울임 대상이 아니고, 그때는 별표를 직접 붙인다.
- HWPX 생성 경로(마크다운 → kordoc)가 별표를 한글 기울임 글자 모양으로 바꾸는지는 확인하지 않았다. HWPX로 낼 때는 산출물을 **사람이 열어** 기울임 적용을 확인한다.

### 자동 검사 범위 (2026-11-22 기준)

| 항목 | 자동 검사 |
|---|---|
| 약자 표기(`A. gigas`)가 앞선 전체 학명 없이 나옴 | **조건부 있음** — `gg_document`가 `scientific_name` 문제로 보고하지만, 속명·종명 **뒤에 대문자로 시작하는 단어(명명자 등)나 `var.`·`subsp.`·`f.`·`ex`·`×`가 올 때만** 학명으로 잡힌다(`gg_document.py`의 `SCI`). 명명자 없이 `A. gigas`만 쓴 약자는 이 검사 밖이라 사람이 확인한다 |
| DOCX에서 속명·종명 기울임 | **부분** — 별표 구간과, 명명자가 뒤따르는 학명만 자동 |
| 명명자·var.를 잘못 기울임 | **없음** — 사람 확인 |
| 첫 등장에 명명자를 빠뜨림 | **없음** — 사람 확인 |
| HWPX 기울임 실제 적용 | **없음** — 사람 확인 |

자동 검사가 없다고 규칙이 없는 것이 아니다. 검토자는 학명이 나온 자리를 찾아 위 표의 "없음" 항목을 직접 본다([cross-review.md](cross-review.md)).

## 2. 본문 인용 표기

작성요령 2쪽 원문:

> (2) 본문에서 인용문헌 표기시 국문논문 저자 2인 경우 저자 사이에 "과", 3인 이상인 경우에는 "등"으로 영문논문 저자 2인 경우 저자명 사이에 "and"로 3인 이상인 경우에는 "Lee et al.," 표시한다. (Kim 과 Lee, 2008; Kim 등, 2008; Lee and Kim, 2008; Lee et al., 2008a, b).

- **국문 논문**
  - 저자 2인: 저자 사이에 "과". 원문 예시는 `(Kim 과 Lee, 2008)`이고 국문 성명 예시는 없다. `(김 과 이, 2008)`처럼 "과" 앞뒤를 띄우는 것은 이 영문 예시에서 옮긴 **추정**이다 — 띄어쓰기는 교수 확인 사항이다.
  - 저자 3인 이상: `(김 등, 2008)`
- **영문 논문**
  - 저자 2인: `(Lee and Kim, 2008)`
  - 저자 3인 이상: `(Lee et al., 2008)` — `et al.` 뒤에 마침표를 찍고, 연도 앞은 쉼표.
- **같은 저자·같은 해 여러 편**: 연도에 a, b를 붙인다. 예: `(Lee et al., 2008a, b)`
- **여러 문헌 나열**: 세미콜론으로 구분한다. 예: `(Kim 과 Lee, 2008; Kim 등, 2008; Lee and Kim, 2008)`
- **(일반 관례 — 학교 원문 아님)** 인용한 문헌은 참고문헌 목록에 같은 철자·같은 연도로 있어야 하고, 어긋나면 오류로 본다. 이 줄은 작성요령 2쪽 원문에 없다. 참고문헌 양식 자체는 [rules/F_format.md](rules/F_format.md)를 따른다.

### 자동 검사 범위 (2026-11-22 기준)

본문 인용 표기("과"·"등"·"and"·"et al.")와 참고문헌 대조를 자동으로 검사하는 경로는 **없다.** 사람이 확인한다. 참고문헌 양식 자체는 [rules/F_format.md](rules/F_format.md)를 따른다.

## 3. 다음 판에서 할 일 (자동화)

- 생성기(md → HWPX)와 재작성본 변환기가 기울임 표시를 한글 기울임 글자 모양으로 옮기는지 실물로 확인하고, 안 되면 옮기게 한다.
- 검사기에 ①학명 첫 등장·약자 순서 ②기울임 누락 ③명명자 기울임 오적용 ④본문 인용-참고문헌 저자·연도 대조를 넣는다.
- 위 자동화 전까지 이 문서의 "사람 확인" 항목은 검토 보고서에 확인 여부를 적는다.
