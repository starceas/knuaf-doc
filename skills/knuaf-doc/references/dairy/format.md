# 낙농전공 논문 서식 규격 (format)

이 문서는 한국농수산대학교 축산학부 낙농전공의 공식 작성요령 5절에 규정된 **학교 공식 규격**을 정리하고, 작성요령에 명시되지 않은 표·그림 등 세부 편집 사항은 스킬 공용 근거를 연결해 명확히 구분한다.

근거: `parsed/1.논문작성요령.md` 5절, `DESIGN-v1.md` F5, 공용 편집 규정 `references/rules/F_format.md`, `references/outputs.md`, `references/figure-photo-policy.md`.

## 1. 학교 공식 규격 — 용지 규격 및 여백

작성요령 5절 1~2항에 명시된 규격이다. 낙농전공의 용지 여백은 공용 기본 서식(위 20, 아래 15, 머리말 15, 꼬리말 15)과 다르므로 아래 치수를 엄수한다.

| 항목 | 낙농전공 공식 규격 | 공용 서식과의 차이 / 비고 |
|---|---|---|
| **판형** | A4 (폭 210.0mm × 길이 296.9mm) | 표준 A4 |
| **위쪽 여백** | **30.0 mm** | 공용(20.0mm)보다 넓음 |
| **아래쪽 여백** | **30.0 mm** | 공용(15.0mm)보다 넓음 |
| **왼쪽 여백** | **30.0 mm** | 좌우 대칭 |
| **오른쪽 여백** | **30.0 mm** | 좌우 대칭 |
| **머리말 여백** | **0.0 mm** | 머리말 영역 없음 (공용 15.0mm와 다름) |
| **꼬리말 여백** | **10.0 mm** | 쪽번호 위치 (공용 15.0mm와 다름) |
| **제본 여백** | **0.0 mm** | 제본 여백 없음 |

## 2. 학교 공식 규격 — 글자꼴 및 본문·제목 배치

작성요령 5절 3~8항에 명시된 규격이다.

### 2.1 본문 서식
- **글자꼴**: 신명조
- **글자 크기**: 12 포인트 (12pt)
- **줄 간격**: **160%** (실측 규격 160% 엄수)
- **정렬 방식**: 양쪽혼합

### 2.2 각 장 및 제목 배치 규칙
- **각 장의 시작**: 각 장은 반드시 **새 쪽(새 페이지)**에서 시작한다 (5절 7항).
- **제목 위아래 행 띄움**: 각 장의 제목 또는 소제목의 **위와 아래는 각각 1행씩 띄운다** (5절 6항).
- **제목 글씨체**: 모든 장의 제목과 소제목은 **굵은 글씨**로 표기한다 (5절 7항).

### 2.3 번호 매김 순서 및 제목 크기 계층
작성요령 5절 8항의 번호 매김 순서(`1 → 가 → 1) → 가) → (1) → (가)`) 및 크기 규정이다.

| 계층 기호 | 서식 역할 | 글자 크기 | 스타일 |
|---|---|---|---|
| **Ⅰ. (로마숫자)** | 요약 대항목, 부록 | **20 포인트** | 굵게 |
| **1.** | 장 제목 (1. 머리말 등) | **18 포인트** | 굵게, 위아래 1행 띄움 |
| **가.** | 절 제목 (가. 창업형태 등) | **16 포인트** | 굵게, 위아래 1행 띄움 |
| **1)** | 항 제목 | **15 포인트** | 굵게 |
| **가)** | 목 제목 | **14 포인트** | 굵게 |
| **(1)** | 세목 제목 | **12 포인트** | 굵게 |
| **(가)** | 세세목 제목 | **12 포인트** | 굵게 |

### 2.4 맞춤법 검사 의무
작성요령 5절 9항에 따라 기본적으로 인쇄 전에 화면상 1회, 인쇄 후 1회 정도 내용 및 맞춤법을 검사해야 한다.

## 3. 학교 공식 규격 — 단위 규정

작성요령 5절 10항 및 본문 지침에 명시된 단위다:
1. **금액 단위**: 반드시 **천원** 단위를 사용한다 (예: `<금액 (천원)>`, `2,000 천원`).
2. **사양·생산 단위**: 일일 섭취량 및 산유량은 **`kg/일`** 단위를 사용한다.
3. **비율 단위**: 백분율 **`%`**를 사용한다.
4. **경지 및 축사 면적**: 반드시 **`m²`** 단위를 사용한다 (작성요령 2-가-4) 명시: "반드시 단위는 m² 사용", 평 단위 단독 표기 금지).
5. **표지 전공 마커**: 표지 심사 마커는 `("낙농",)`으로 고정한다 (공용 레지스트리 계약).

## 4. 앞부분 양식 확인 항목 (표지·제출지·인준지·학부모 동의서)

작성요령 8쪽 목차에 '학부모 동의서 (도장필요)'가 있다. 앞부분 문서의 구성·순서·쪽수는 공식 양식에서 확인해 기록한다.

학교 배포 양식 원본(`1.논문작성요령-낙농전공.pdf`, `1.논문작성요령.hwp`)에는 앞부분 문서들의 개별 항목별 글자 크기·정렬·행간 수치가 기재되어 있지 않다. 아래 항목의 글자 크기·정렬·행간은 모두 미확인이며, 임의 추측값을 넣지 않고 공식 HWP 양식이 확인되기 전까지 **"학교 양식 확인 필요"**로 관리한다.

| 문서 | 확인할 항목 (글자 크기·정렬·행간 미확인) | 확인된 특이사항 |
|---|---|---|
| **표지** | 논문 제목, 학과/전공명, 지도교수·학생 성명, 제출 연월 | 학교 배포 양식 원본 미기재 (학교 양식 확인 필요) |
| **제출지** | 논문 제목, 제출문, 전공, 학생 성명 | 학교 배포 양식 원본 미기재 (학교 양식 확인 필요) |
| **인준지** | 논문 제목, 심사위원장·심사위원 성명, 인준 연월일 | 학교 배포 양식 원본 미기재 (학교 양식 확인 필요) |
| **학부모 동의서** | 제목, 동의 확인 문구, 서명·날인란 | 8쪽 목차에 명시, 날인란 도장 필요 ("도장필요") |

- **스킬 출력 밖 앞부분 문서**: 학부모 동의서 등 앞부분 문서가 스킬 출력에 없으면 학생이 직접 넣고 최종 PDF에서 포함 여부와 쪽 나눔을 확인한다.

## 5. 보조 편집 지침 (학교 5절 외 스킬 공용 근거 연결)

학교 작성요령 5절에는 문단 들여쓰기 폭, 표·그림의 캡션 위치 및 출처 표기 규칙이 명시되어 있지 않다. 따라서 아래 사항은 학교 공식 5절 규격이 아니며, 스킬의 공용 편집 지침([F_format.md](../rules/F_format.md), [outputs.md](../outputs.md), [figure-photo-policy.md](../figure-photo-policy.md))을 준용하는 보조 지침이다.

### 5.1 문단 서식 및 표·그림 배치 보조 지침
- **문단 들여쓰기**: 공용 문서 규칙([F_format.md](../rules/F_format.md) F1-04)에 따라 문단 시작 시 2칸 들여쓰기를 권장한다 (학교 5절 자체 규정은 아님).
- **표 제목**: 상단에 표기하며 우측 또는 제목 끝에 단위를 병기한다 (예: `(단위: 천원, 두)`).
- **그림/사진 캡션**: 캡션 위치와 사진 규격은 공용 [figure-photo-policy.md](../figure-photo-policy.md)를 따른다.

### 5.2 출처 표기 원칙 (외부 자료 vs 직접 산출 구분)
- **외부 공식 자료 인용 및 재가공·재계산 표**:
  - 외부 통계(KOSIS, 낙농진흥회, 축평원 등)를 직접 인용하거나 이를 기초로 가공·재계산한 표는 제목 끝 `(출처 : 기관명)` 또는 표 하단 `주 :`에 원천 출처(자료명, 기준연도, 산출 기준)를 반드시 표기한다. 외부 데이터를 바탕으로 학생이 계산을 수행했다고 해서 원출처 표기를 생략할 수 없다.
- **순수 본인 직접 조사·관측·촬영 자료**:
  - 학생 본인의 농장 실측값, 본인 및 가족이 직접 촬영한 사진, 순수 자체 수립 계획 표에는 출처를 표기하지 않는다 (공용 `outputs.md` 출처 규칙).
