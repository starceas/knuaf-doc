# 낙농전공 논문 서식 규격 (format)

이 문서는 한국농수산대학교 축산학부 낙농전공의 공식 작성요령 5절에 규정된 **학교 공식 규격**을 정리하고, 작성요령에 명시되지 않은 표·그림 등 세부 편집 사항은 스킬 공용 근거를 연결해 명확히 구분한다.

근거: `parsed/1.논문작성요령.md` 5절, `DESIGN-v1.md` F5, 공용 편집 규정 `references/rules/F_format.md`, `references/outputs.md`, `references/figure-photo-policy.md`.

## 1. 학교 공식 규격 — 용지 규격 및 여백

작성요령 5절 1~2항에 명시된 규격이다. 낙농전공의 용지 여백은 공용 기본 서식(위 20, 아래 15, 머리말 15, 꼬리말 15)과 다르므로 아래 치수를 엄수한다.

| 항목 | 낙농전공 공식 규격 | 공용 서식과의 차이 / 비고 |
|---|---|---|
| **판형** | A4 (폭 210.0mm × 길이 296.9mm) | 표준 A4 |
| **위쪽 여백** | **30.0 mm** | 공용(20.0mm)보다 넓음 |
| **아래쪽 여백** | **30.0 mm** | 공용(15.0mm)보다 넓음 |
| **왼쪽 여백** | **30.0 mm** | 좌우 대칭 |
| **오른쪽 여백** | **30.0 mm** | 좌우 대칭 |
| **머리말 여백** | **0.0 mm** | 머리말 영역 없음 (공용 15.0mm와 다름) |
| **꼬리말 여백** | **10.0 mm** | 쪽번호 위치 (공용 15.0mm와 다름) |
| **제본 여백** | **0.0 mm** | 제본 여백 없음 |

## 2. 학교 공식 규격 — 글자꼴 및 본문·제목 배치

작성요령 5절 3~8항에 명시된 규격이다.

### 2.1 본문 서식
- **글자꼴**: 신명조
- **글자 크기**: 12 포인트 (12pt)
- **줄 간격**: **160%** (실측 규격 160% 엄수)
- **정렬 방식**: 양쪽혼합

빌더가 넣는 값: Word는 본문 12pt·줄 간격 160%·양쪽 정렬을 지정한다. 한글은 F11부터 학교 앞부분이 갖춰져 구역 분할이 적용된 원고의 일반 본문에 12pt를 적용하며, 단계 제목에는 프로필의 크기·굵기를 적용한다. 한글 표 칸·표/그림 설명은 10pt 그대로다. 한글의 일반 본문 크기·줄 간격·정렬은 낙농 전용 검사기의 검사 대상이 아니므로 직접 확인한다(§6). 신명조 설치·글꼴 대체 여부도 사람 확인 항목이다.

### 2.2 각 장 및 제목 배치 규칙
- **각 장의 시작**: 각 장은 반드시 **새 쪽(새 페이지)**에서 시작한다 (5절 7항).
- **제목 위아래 행 띄움**: 각 장의 제목 또는 소제목의 **위와 아래는 각각 1행씩 띄운다** (5절 6항).
- **제목 글씨체**: 모든 장의 제목과 소제목은 **굵은 글씨**로 표기한다 (5절 7항).

빌더가 넣는 값: 본문 단계 제목 위아래에 19.2pt(Word 384 twips, 한글 1920 HWPUNIT)를 지정하고, 두 번째 장부터 쪽 나눔을 넣으며 제목은 굵게 낸다. 학교 앞부분이 있는 원고의 첫 장은 본문 구역 시작이 새 쪽을 연다. F13부터 `Ⅰ. 머리말`도 본문 시작으로 찾고 `Ⅺ`·`Ⅻ`도 장 제목으로 읽는다. 두 검사기가 제목 크기·간격·쪽 나눔을 대조하지만 실제 쪽 배치는 최종 PDF에서도 확인한다(§6).

### 2.3 번호 매김 순서 및 제목 크기 계층
작성요령 5절 8항이 정한 번호 매김 순서(`Ⅰ → 1 → 가 → 1) → 가) → (1) → (가)`)와 단계별 글자 크기다. 크기는 **단계(깊이) 순서**로 매겨진다: 20 → 18 → 16 → 15 → 14 → 12 → 12 포인트.

| 계층 기호 | 서식 역할 | 글자 크기 | 스타일 |
|---|---|---|---|
| **Ⅰ. (로마숫자)** | 장 제목 (요약 대항목, 부록 포함) | **20 포인트** | 굵게, 장마다 새 쪽 |
| **1.** | 절 제목 (Ⅰ. 장을 쓸 때) | **18 포인트** | 굵게, 위아래 1행 띄움 |
| **가.** | 항 제목 | **16 포인트** | 굵게, 위아래 1행 띄움 |
| **1)** | 목 제목 | **15 포인트** | 굵게 |
| **가)** | 세목 제목 | **14 포인트** | 굵게 |
| **(1)** | 세세목 제목 | **12 포인트** | 굵게 |
| **(가)** | 그 아래 단계 | **12 포인트** | 굵게 |

**두 가지 장 표기와 크기 순서** — `Ⅰ.`로 장을 쓰면 `Ⅰ.20 → 1.18 → 가.16 → 1)15 → 가)14 → (1)12 → (가)12`다. `1.`로 장을 쓰는 원고(스킬 생성기 기본형)는 `1.20 → 가.16 → 1)15 → 가)14 → (1)12 → (가)12`로 18pt 단계를 쓰지 않는다. 끝의 두 기호는 별개 단계지만 같은 12pt다.
- 빌더는 원고를 읽어 정한 제목 단계에 프로필 `level_pt`를 적용한다. Word 검사기는 제목 스타일·개요 수준으로 단계를 읽고, 한글 검사기는 본문 첫 장의 번호 모양으로 위 두 크기 순서 중 하나를 골라 대조한다. 한글 검사기는 첫 장 번호를 읽지 못하면 단계 판정 불가로 보고한다.
- 두 검사기의 기대값은 빌더 프로필을 읽지 않고 별도로 선언되어 있다. `(1)`·`(가)`의 12pt와 나머지 단계 크기는 현재 낙농 프로필과 같다.

### 2.4 맞춤법 검사 의무
작성요령 5절 9항에 따라 기본적으로 인쇄 전에 화면상 1회, 인쇄 후 1회 정도 내용 및 맞춤법을 검사해야 한다.

## 3. 학교 공식 규격 — 단위 규정

작성요령 5절 10항 및 본문 지침에 명시된 단위다:
1. **금액 단위**: 반드시 **천원** 단위를 사용한다 (예: `<금액 (천원)>`, `2,000 천원`).
2. **사양·생산 단위**: 일일 섭취량 및 산유량은 **`kg/일`** 단위를 사용한다.
3. **비율 단위**: 백분율 **`%`**를 사용한다.
4. **경지 및 축사 면적**: 반드시 **`m²`** 단위를 사용한다 (작성요령 2-가-4) 명시: "반드시 단위는 m² 사용", 평 단위 단독 표기 금지).
5. **표지 전공 마커**: 표지 심사 마커는 `("낙농",)`으로 고정한다 (공용 레지스트리 계약).

## 4. 앞부분 양식 확인 항목 (표지·제출지·인준지·학부모 동의서)

작성요령 8쪽 목차에 '학부모 동의서 (도장필요)'가 있다. 앞부분 문서의 구성·순서·쪽수는 공식 양식에서 확인해 기록한다.

학교 배포 양식 원본(`1.논문작성요령-낙농전공.pdf`, `1.논문작성요령.hwp`)에는 앞부분 문서들의 개별 항목별 글자 크기·정렬·행간 수치가 기재되어 있지 않다. 그래서 스킬은 **선배 논문(견본) 실측값을 정리한 낙농 서식 프로필**(`gg_major_format.DAIRY_PROFILE`)을 적용하고, 학교 양식과 실제 배치가 맞는지는 사람이 최종 PDF에서 확인한다(§6). 아래 표는 자동 적용값이며, 모든 항목을 두 검사기가 전부 검사한다는 뜻은 아니다.

| 문서 | 담을 항목 | 빌더가 넣는 값 (견본 실측 F-0) | 확인된 특이사항 |
|---|---|---|---|
| **겉표지** | 학위 문구, 논문 제목, 제출 연월, 학교·학과·전공, 학생 성명, 지도교수 | 학위 줄 18pt 보통 / 계획 제목 32pt 굵게 / 지도교수 줄 18pt 보통 / 나머지 20pt | 무번호(쪽번호 없음). 제목 식별 조건은 아래 참조 |
| **제출지** | 논문 제목, 제출문, 전공, 학생 성명 | 계획 제목 32pt 굵게 / '이 논문을 …으로 제출함' 줄 18pt 보통 / 나머지 20pt | 무번호 |
| **인준지** | 논문 제목, 심사위원장·심사위원 성명, 인준 연월일 | 계획 제목 32pt 굵게 / '… 인준함'·위원장·위원 줄 18pt 보통 / 나머지 20pt | 무번호. 날인 `(인)` 자리 확인 |
| **학부모 동의서** | 제목, 동의 확인 문구, 서명·날인란 | 제목 22pt 굵게, 본문 12pt, `※` 안내 10pt | 겉표지와 함께 **무번호 구역**에 온다. 날인란 도장 필요("도장필요") |

- **앞부분 문서는 원고의 역할 구분을 바탕으로 출력한다**: 위 네 문서는 무번호 구역에 두고, 요약 앞에서 로마 대문자 쪽번호 구역을 연다. F12부터 한글 동의서 제목 22pt 굵게·겉표지 학위 줄 18pt 보통도 적용한다. 학생 성명·서명·도장은 자동으로 확정하지 않는다.
- **제목 식별 조건**: Word는 전공 계획명(`spec.plan_label`)과 글자가 같은 줄에 32pt 굵게를 적용한다. 한글은 그 줄이 없으면 학위 줄 다음 문단을 제목으로 본다. 자유 제목을 쓴 원고는 두 형식의 크기·순서를 직접 확인한다.
- **사람 확인**: 문서별 쪽 나눔·가운데 정렬·항목 겹침은 최종 PDF에서 확인한다. 한글 겉표지에서 제목 바로 다음 줄은 학위·제출문·지도교수 등 별도 문구로 분류되지 않으면 20pt 굵게로 나오므로, 해당 줄의 내용도 확인한다.

## 5. 보조 편집 지침 (학교 5절 외 스킬 공용 근거 연결)

학교 작성요령 5절에는 문단 들여쓰기 폭, 표·그림의 캡션 위치 및 출처 표기 규칙이 명시되어 있지 않다. 따라서 아래 사항은 학교 공식 5절 규격이 아니며, 스킬의 공용 편집 지침([F_format.md](../rules/F_format.md), [outputs.md](../outputs.md), [figure-photo-policy.md](../figure-photo-policy.md))을 준용하는 보조 지침이다.

### 5.1 문단 서식 및 표·그림 배치 보조 지침
- **문단 들여쓰기**: 공용 문서 규칙([F_format.md](../rules/F_format.md) F1-04)에 따라 문단 시작 시 2칸 들여쓰기를 권장한다 (학교 5절 자체 규정은 아님).
- **표 제목**: 상단에 표기하며 우측 또는 제목 끝에 단위를 병기한다 (예: `(단위: 천원, 두)`).
- **그림/사진 캡션**: 캡션 위치와 사진 규격은 공용 [figure-photo-policy.md](../figure-photo-policy.md)를 따른다.

### 5.2 출처 표기 원칙 (외부 자료 vs 직접 산출 구분)
- **외부 공식 자료 인용 및 재가공·재계산 표**:
  - 외부 통계(KOSIS, 낙농진흥회, 축평원 등)을 직접 인용하거나 이를 기초로 가공·재계산한 표는 제목 끝 `(출처 : 기관명)` 또는 표 하단 `주 :`에 원천 출처(자료명, 기준연도, 산출 기준)를 반드시 표기한다. 외부 데이터를 바탕으로 학생이 계산을 수행했다고 해서 원출처 표기를 생략할 수 없다.
- **순수 본인 직접 조사·관측·촬영 자료**:
  - 학생 본인의 농장 실측값, 본인 및 가족이 직접 촬영한 사진, 순수 자체 수립 계획 표에는 출처를 표기하지 않는다 (공용 `outputs.md` 출처 규칙).

## 6. 자동으로 되는 것과 사람이 확인할 것

아래는 **학교 앞부분이 갖춰져 구역 분할이 적용된 낙농 원고** 기준이다. `--major dairy`로 빌드한 뒤 Word는 `gg_school_format.py <docx> --major dairy`, 한글은 `gg_school_format_hwpx.py <hwpx> --major dairy`로 별도 검사한다. 검사기는 위반을 보고할 뿐 파일을 고치지 않는다. 자동 적용과 기계 검사를 구분해 읽는다.

| 항목 | 빌더 자동 적용 | 기계 검사 | 사람이 확인·마무리 |
|---|---|---|---|
| 여백 위·아래·좌·우 30 mm, 머리말 0 mm, 꼬리말 10 mm, 제본 0 mm | 겉표지·앞부분·본문 세 구역 | 두 검사기 모두 구역별 대조 | 최종 PDF에서 배치 확인 |
| 쪽번호 구역 | 무번호 앞부분 / 요약부터 로마 대문자 I / 본문부터 아라비아 1 | 두 검사기 모두 형식·다시 시작 값 대조 | 요약 `- I -`·본문 `- 1 -` 시작을 실제 화면에서도 확인 |
| 쪽번호 꼴·크기 | Word `- N -` 9pt / 한글 `sideChar="-"` | Word는 꼴·9pt, 한글은 위치·번호 형식·장식 문자 검사 | 한글의 9pt·하이픈 주변 공백은 기계 판정하지 않으므로 렌더에서 확인 |
| 본문 글자 12pt | Word 12pt / 한글 F11부터 일반 본문 12pt | Word는 12pt 검사 / 한글 낙농 검사기는 일반 산문 크기를 검사하지 않음 | 한글 본문 크기 확인. 한글 표 칸·표/그림 설명은 10pt로 별도 적용 |
| 본문 줄 간격 160%·양쪽 정렬 | Word는 160%·양쪽 정렬 지정 | Word는 두 값 검사 / 한글 낙농 검사기에 이 두 값의 대조 없음 | 한글에서 줄 간격·정렬을 작성요령과 대조 |
| 장마다 새 쪽 | 첫 장은 본문 구역 시작, 나머지 1단계 제목에 쪽 나눔. 한글은 원고의 1단계 제목 글자 목록으로 적용 | 두 검사기 모두 장 경계 대조 | 실제로 장이 새 쪽에서 시작하는지 최종 PDF 확인 |
| 단계 제목 크기·굵기 | §2.3의 크기 순서와 굵게 적용 | Word는 스타일·개요 수준, 한글은 번호 모양으로 대조 | 글꼴 대체·굵기 표시 확인 |
| 본문 단계 제목 위아래 19.2pt | Word 384/384 twips / 한글 개요 문단 모양에 1920/1920 HWPUNIT | Word는 문단 간격, 한글은 제목 문단이 실제 참조하는 모양의 간격 검사 | 최종 PDF에서 띄움 확인 |
| 요약·감사의 글·목차·표/그림 목차·동의서 제목 22pt 굵게 | 두 빌더 모두 적용(F12, 로마 첫 장 경계는 F13) | Word는 요약·감사의 글·동의서만 검사. 한글은 여섯 제목 검사(표/그림 목차는 있을 때) | Word 목차류 제목은 기계 검사 밖이므로 직접 확인 |
| 겉표지·제출서·인준서 줄 크기·동의서 본문 | §4의 값 적용 | 한글은 겉표지 크기·동의서 제목/구역 검사. Word 낙농 전용 검사는 이 표의 각 줄 크기를 대조하지 않음 | 계획 제목 식별·서명/날인·줄별 크기·가운데 정렬·겹침 확인 |
| 표 폭 | 한글은 본문 폭 150 mm로 맞춤 | 한글 검사기는 구조·재파싱도 확인하지만 실제 배치의 눈 검사를 대신하지 않음 | 표·그림·머리행·쪽 넘김 확인 |
| 목차 쪽번호 실제 값 | Word는 갱신 전 `PAGEREF` 필드 / 한글은 자동 필드 없음 | 실제 페이지와의 일치 검사는 별도 사람 확인 | Word 필드 갱신, 한글 쪽번호 직접 입력 후 대조 |
| 신명조 글꼴 | 글꼴 이름 지정 | 설치 여부는 검사하지 않음 | 신명조 설치·대체 글꼴 여부 확인 |

검사 통과는 제출용 편집 완료가 아니다. 프로필의 `finish_notice`·`human_finish`대로 학교 원문·전체 페이지·표·그림을 최종 확인한다. 후처리로 다시 저장했다면 DOCX는 `--rehash`로 매니페스트의 파일 해시(파일 식별값)를 갱신한다.

### 7.2 현재 한계·사람 확인

| 한계 | 현재 동작 / 할 일 | 코드 근거 (`scripts/` 기준) |
|---|---|---|
| Word 목차·표 목차·그림 목차 제목은 검사 밖 | 빌더는 22pt 굵게로 내지만 Word 검사기의 특수 제목 목록은 요약·감사의 글·동의서뿐. 목차류 제목은 직접 확인 | `gg_school_format.py` `DAIRY_FRONT_TITLES` |
| 한글 일반 본문 크기·줄 간격·정렬은 낙농 전용 검사 밖 | F11의 12pt 적용과 검사 범위는 별개. 한글에서 직접 확인 | `gg_school_format_hwpx.py` `_dairy_check_levels`·`check` |
| 한글 목차 쪽번호는 자동이 아님 | 실제 쪽을 보고 직접 입력. Word도 `PAGEREF` 필드 갱신 필요 | `gg_hwpx.py` `_front_charpr_targets`, `gg_frontmatter_layout.py` `page_reference` |
| 학교 앞부분 없는 원고는 학교 서식 전체 적용과 다름 | Word는 쪽번호 바닥글을 만들지 않음. 한글은 세 구역 분할을 건너뛰고 앞부분/본문 글자 크기 후처리도 적용하지 않음. 학교 앞부분이 있는 완성 원고로 다시 빌드하고 확인 | `build_docx.py` `convert`, `gg_hwpx.py` `split_sections_by_plan`·`transform_hwpx` |
| 실제 `머리말` 장이 없는 원고는 본문 경계 오인 가능 | 낙농은 목차 뒤 감사의 글 다음 위치 또는 번호 1의 머리말을 찾고, 못 찾으면 목차 바로 다음을 본문으로 삼음. 목차의 머리말 항목만 있고 실제 장이 없는 경우도 직접 확인 | `gg_document.py` `school_frontmatter_plan` |
| 자유 제목의 식별·겉표지 줄 순서 | Word는 전공 계획명과 일치하는 줄만 32pt, 한글은 없으면 학위 다음 줄을 제목으로 취급. 한글의 제목 다음 줄은 별도 문구 분류에 해당하지 않으면 20pt 굵게. §4의 값·순서를 최종 PDF에서 확인 | `gg_frontmatter_layout.py` `_cover_text_key`, `gg_hwpx.py` `_peer_block_targets` |
| 렌더에서만 보이는 상태 | 쪽 나눔·가운데 정렬·표 폭·글꼴 대체·한글 쪽번호 9pt/공백은 기계 검사만으로 확정하지 않음 | `gg_major_format.py` `DAIRY_FINISH_NOTICE`·`DAIRY_HUMAN_FINISH`, `gg_school_format_hwpx.py` `_dairy_notes` |

따라서 “낙농 한글 산출물은 예전 결함 때문에 반드시 검사에서 막힌다”는 설명은 현재 상태에 맞지 않는다. 검사 결과는 해당 파일의 실제 위반 목록으로 판단하고, 자동으로 고쳐진 값과 사람이 마무리할 항목을 나눠 확인한다.
