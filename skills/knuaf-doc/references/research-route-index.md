# 한국농수산대학교 논문 리서치 경로 통합 인덱스

- 최신성 경계: 2026-11-04 관찰 기준이며 오늘 최신성 확인 아님. 미확인 통계는 탐색 후보.
- 기본 원칙: 선배 논문 수치·재배법 상속 금지. 외부 통계는 비교 벤치마크이며 학생 계획값으로 자동 승격하지 않음.
- 원예환경시스템: 본문 초안(글)은 [전공별 본문 초안 안내](major-body-draft.md)에 따라 작성할 수 있다. 이 색인은 [원예환경시스템 README](hort-env-systems/README.md)와 리서치 경로만 연결한다.
- **모든 전공의 자료 역할·우선순위**: 작성요령이 선배 논문보다 우선한다. ① 작성 규칙·지침은 아래 A/B 구분으로 적용하는 출발 기준이다. ② 선배 본문은 흐름·구성의 참고 견본이며, 교수의 세부 확인이나 다른 형식의 허용을 입증하지 않는다. 선배에 있다는 이유로 작성요령과 다른 형식을 허용하지 않는다. ③ 재무 엑셀은 시트·수식 구조를 포함한 양식 자체가 정본이며 기존 내용·숫자는 학생 값으로 바꾼다.
- **작성자와 내용의 구분**: 선배 본문과 엑셀의 작성자는 같을 수도, 다를 수도 있다. 같은 학생의 동일 계획이라고 가정하지 않으며, 견본끼리 이름·작목·숫자가 다르다는 이유로 충돌 보고·정정·숫자 맞추기를 하지 않는다.
- **재무의 기초는 엑셀**: 제공 재무 엑셀의 시트·수식 구조를 보존하고 학생의 입력값(내용)만 바꾼다. 논문 견본의 숫자에 맞추려고 수식을 고치지 않는다. 수식 문제나 적용 한계가 발견되면 임의 수정 대신 근거와 한계를 알린다. 현재 미지원 출력·계산 범위는 그대로다.
- **A — 형식 규칙은 준수·검사 대상**: 그림·표 제목 위치와 번호, 사진·자료 출처 표기, 참고문헌 양식, 띄어쓰기·줄바꿈·글꼴·글자 크기, 쪽번호, 단위·숫자 표기, 목차 형식은 지킨다. 어기면 수정하도록 알리며 “의도면 OK”로 면제하지 않는다.
- **B — 내용·구성 규칙은 기준선**: 장·절에서 무엇을 얼마나 쓸지, 하위 항목 순서, 분량, 예시 문장은 사업에 맞게 조정할 수 있다. 차이는 “내용·구성이 기준과 다름 — 의도면 OK”로 알리고 의도를 확인한다. 선배와 다르다는 이유만으로 차단하지 않는다.
- **판단 기준과 고정 규칙**: 독자가 ‘양식이 틀렸다’고 보면 A, ‘내용 구성이 다르다’고 보면 B다. 애매하면 A로 적용하고 형님이 명시적으로 풀어 준 경우에만 B로 바꾼다. 목차의 표기 형식(A)과 장·절의 내용 배치(B)를 혼동하지 않는다. 엑셀 구조·수식 유지, 재무의 엑셀 기준, 낙농 문체 등 형님 고정 규칙과 같은 학생의 본문/엑셀 검산·공식 통계 원문 확인은 유지한다.

## 4. 리서치 실행 원칙 및 빈 자료 처리

1. **실행 표준 순서**:
   - `장의 역할` → `필요 근거` → `1순위 기관/URL` → `선택조건/대체` → `금지 전이 차단` → `다음 장 인계 (근거·제약)`.
   - 다음 장 인계는 근거·제약·미해결 조건의 전달이며, 외부 통계 수치의 자동 승격이 아님.
2. **빈 자료 (Data Absence) 처리**:
   - 유사 품목 수치 복제 금지, 0원 처리 금지.
   - 공식 통계 부재 시 지자체 기술센터 실증 자료나 실제 거래 견적 등 직접 조사로 보완하며, 근거 확보 전까지 해당 항목 계산을 보류(Held)함.
