# 조사 경로 (어디부터 뒤지는가)

`research-routing.md`가 **누구에게 맡기는가**를 정한다면, 이 문서는 **어디를 여는가**를 정한다.

> ℹ️ **출처 제한 적용 범위**: 비공식 자료(기사·블로그·SNS 등) 인용 전면 금지 및 공식 통계 한정 조사는 **모든 전공 공통 기본값**이다([사용자 결정 2026-10-06 22:39]). 전 전공에서 공공 통계·학술·정규교재·본인 직접 조사 외 비공식 자료는 배제된다.

검색엔진부터 시작하면 블로그·쇼핑몰이 먼저 걸리고, 등급 미달 자료를 들고 와서
결국 다시 조사하게 된다. 조사 유형별로 갈 곳이 정해져 있다.

### 물가상승률 및 노무비 조사 원칙 (R1 권고 및 지적 6 반영)

1. **공식 통계 선택 기준**:
   - **일반물가 (자재·경비 공통)**: 국가데이터처 KOSIS 소비자물가지수 전국 총지수(`DT_1J22003`, id `official.kosis.cpi.total`). 세부 자재·경비는 농가구입가격지수 재료비·경비(`DT_1J62`)를 쓴다.
   - **노무비 (고용노동임금)**: KOSIS 농가구입가격지수 노무비(`DT_1J62`, id `official.kosis.farm_purchase.labor`). 템플릿 임금 관측은 원/일 수열만 직접 허용되며, 시간급(원/시간)을 일급으로 환산할 때는 `unit_conversion` 명시 계약이 필수다 (기본 환산 시간 없음, Q-W-B2 사용자/조사 후 결정 대기).
   - **판매가 (매출)**: 농촌진흥청 농산물소득자료집 동일 작목·재배형태·지역의 주산물 단가. **농가판매가격지수 총지수(`DT_1J60`)는 여러 품목의 총합이므로 특정 작목 판매가로 자동 대입하지 않는다.** 번들 KAMIS 쌀 수열 또한 시장 참고용(`allowed_roles: []`)으로 판매가 적용이 불가하다.
2. **세 상승률의 완전 분리**:
   - 일반물가, 노무비(임금), 판매가 상승률은 성격이 전혀 다르므로 반드시 분리하여 조사·적용한다. 하나의 물가상승률로 통일하거나 임의 상수를 쓰지 않는다.
3. **상승률 결정 원칙 (관측 CAGR 강제) 및 산식**:
   - 상승률 r은 **공식 관측 수열의 끝점 연평균 변화율(CAGR)로만 산출**된다. 명시 r 입력은 검산용(`max(5e-4, 0.05 × |CAGR|)` 허용오차 일치)이며, 관측 없는 r이나 임의 계획 가정 r은 입력할 수 없다.
   - 산식은 연평균 변화율(CAGR): `r = (V_end / V_start)^(1 / (end_year - start_year)) - 1`. 내부 배율은 `1 + r`.
   - 계획연도 배율은 `(1 + r)^(계획연도 - application_base_year)`이며 적용 횟수는 연도 차이와 같다.
4. **이중 적용 금지**:
   - 노무비 단가에 임금 상승률을 곱한 뒤 노무비 총액에 일반물가를 다시 곱하지 않는다. 감가상각비와 고정 차입금 원리금에는 물가상승률을 적용하지 않는다.
5. **판매가 차원 일치 및 계획 권위 원칙**:
   - 사업계획의 최상위 차원(`crops`, `region`, `cultivation` 등)이 절대적 기준이며 보조 선언이 충돌하면 거부된다. 판매 수열이 선언한 모든 차원(단위 포함)은 계획이 같은 값으로 확정해야 한다(`crop` 필수).
   - `전국`은 고정 지역값이며 와일드카드가 아니다. 학생 작목의 동일 조건 공식 단가 수열이 없을 경우, 임의 값을 추정하거나 다른 작목을 대입하지 않고 "판매가 상승 미반영(확인 불가)"을 명시 선택한다.
6. **학생 직접 입력 수열(`price_sources`)의 공식 출처 및 엄격 URL 계약**:
   - 학생 수열도 공공기관 종류(`agency_kind`), 엄격 https 공식 도메인(`go.kr`, `kosis.kr`, `kamis.or.kr`, `re.kr` 계열), `evidence_locator`, `base_year`, `unit`, `dimensions`, `allowed_roles`가 필수다.
   - 백슬래시(`\`), `@`(userinfo), 공백, 제어문자, NBSP, 443 외 포트, 빈 host/port, 유니코드/IDNA 변형(punycode `xn--`), 점 경로(`.`, `..`, `%2e`), 불완전 percent-escape, 빈 `?`/`#` 등 모호한 URL은 입력 단계에서 즉시 거부된다. 관측/미확인 연도 교집합도 거부된다.
7. **확인 불가 원칙 및 증거 명시**:
   - 공식 통계에서 확인되지 않은 연도나 수치는 임의 추정 없이 `확인 불가`로 표기한다. 증거 원장에 출처 ID, 기준연도, 통계표 명칭을 명시한다.

DBpia(dbpia.co.kr)는 기관 인증이 필요하다. **KCI·ScienceON을 먼저 본다.**
거기서 오픈액세스 원문이 나오면 유료DB에 갈 필요가 없다.

진입 화면 응답과 실제 자료 확보는 구별한다. 홈페이지가 리다이렉트나 자바스크립트 화면이면 확인된 도착 URL을 기록하고, 검색 조건·대상 기간·실제 결과까지 읽었는지 따로 남긴다. 브라우저가 없는 환경에서는 정적 원문을 확보하거나 사용자 제공 자료로 이어간다. 폼·메뉴만 확인한 것을 통계·가격·논문 본문 확보로 처리하지 않는다. 농가판매가격지수는 원/kg 단가가 아니며 미확인 농가 수취가격을 대신하지 않는다.

**학위논문은 DOI가 없는 경우가 많다.** 학술적 사실(생육조건·성분)의 근거로 쓸 때는
학위수여기관·연도·페이지를 특정하고, 가능하면 같은 내용의 학술지 논문을 함께 확보한다.
Ⅲ-6 관련논문은 DOI 확인이 가능한 학술지 논문을 우선한다.

## 4. 작물명 별칭 확인 (조사 전 필수)

같은 작물이 사이트마다 다른 이름으로 등록되어 있다.
**별칭을 확인하지 않고 "결과 없음"을 없다고 판정하지 않는다.**

### 확인할 이름 4종

    정식명       농림축산식품부·통계청 분류명
    한약재명     약용작물이면 생약명 (예: 도라지 → 길경)
    학명         학술DB 검색용
    통계 분류명   KAMIS·KOSIS의 상위 품목명 (예: 새싹삼 → 인삼류)

### 절차

1. 작목이 확정되면 **조사 착수 전에 한 번** 별칭을 찾는다
2. 정식명·학명 확인: 국가표준식물목록 nature.go.kr/kpni, 농사로 작목정보
3. 약용작물이면 생약명 확인: 식약처 의약품통합정보시스템 nedrug.mfds.go.kr,
   국가한의임상정보포털 nikom.or.kr
4. KAMIS·KOSIS에서 그 작목이 **어느 상위 품목에 묶여 있는지** 확인한다
5. 찾은 별칭을 `04_research_log.md` 맨 앞에 기록한다

### 결과 없음 판정 규칙

**별칭 2개 이상으로 확인한 뒤에만 "통계 없음"으로 결론 내린다.**

신규·소면적 작목은 독립 통계가 없는 경우가 많다. 그때는
상위 품목 통계를 쓰고 **그 사실을 본문에 밝힌다.** 없는 통계를 지어내지 않는다.

별칭은 정본으로 관리하지 않는다. 작목·전공마다 다르고 분류가 개편되므로
**그때그때 조사해 작업 폴더에 남긴다.**

## 5. 위임 프롬프트 템플릿

조사를 위임할 때 아래를 **한 묶음으로** 전달한다. 질문만 던지면 검색엔진부터 헤맨다.

    [조사 유형] 도매 시세 (농가 수취가 아님)
    [필요 출처] 정부·공공기관 공식 통계 또는 학술자료 ([source-intake.md](source-intake.md) 3항 준수)
      ※ 언론 기사, 블로그, 쇼핑몰, 개인 SNS, 타인 인터뷰 등 비공식 자료는 일체 인용 불가

    [1순위] KAMIS kamis.or.kr — 품목별 도매가격
    [2순위] KOSIS kosis.kr — 농축산물 가격 통계
    [3순위] 지역 농협·공판장 공식 공시

    [검색어] 정식명 / 한약재명 / 상위 품목명 (별칭 전부 시도)

    [중단 조건]
    - 3순위까지 확인해도 공식 통계가 없으면 멈추고 "확인 불가"로 보고한다
    - 비공식 자료(블로그·쇼핑몰·기사)가 검색되더라도 이를 인용하지 않는다
    - 확인 못 한 값은 "확인 불가"라고 하라. 지어내거나 추정하지 마라

    [결과 서식]
    | 주장 | 출처기관 | 자료명 | 기준연도 | URL | 출처구분 |
    확인한 것과 배제한 것을 모두 적고, 배제 사유를 밝힐 것

## 6. 중단하고 보고할 때

1~3순위에서 못 찾았다고 실패가 아니다. **그 사실 자체가 조사 결과다.**

    보고 예: "KAMIS·KOSIS에 이 작목 독립 통계가 없다.
             상위 품목(인삼류) 통계는 있다. 독립 품목 가격은 공식 확인 불가다."

주 모델이 이 보고를 받아 판단한다.
상위 품목 통계를 인용할지, 해당 항목을 "확인 불가"로 둘지, 사용자에게 직접 확인할지는 주 모델과 학생이 정하며, 위임받은 모델이 임의로 비공식 자료를 대체 채택하지 않는다.

## 7. 하지 않을 것

- 검색엔진을 1순위로 쓰기 (2·3항 표에 있는 조사는 사이트를 직접 연다)
- 유통단계 판정 없이 "단가" 조사하기
- 별칭 확인 없이 "결과 없음" 판정하기
- 1순위에서 못 찾았다고 곧바로 기사·블로그·쇼핑몰로 내려가기 (비공식 자료 인용 금지)
- 확인하지 못한 값을 임의 추정하거나 유추하여 제시하기
- 위임받은 모델이 비공식 자료나 카더라 기사로 대체 판단하기
