# 본문과 재무계획 대조

적용 범위: 모든 전공. 본문·요약·표 셀의 판로 시작 연도·판매비율·단가를 재계산한 재무 엑셀과 대조한다. 이전 본문의 값이나 다른 판로 값을 복사하지 않는다.

이 문장 해석 검사는 **'fail이면 확실히 틀림'만 보장하는 보조 검사**다. **'pass'는 '비교한 주장에서 모순을 못 찾음'일 뿐 본문 전체가 맞다는 근거가 아니다.** 보장은 검토한 값 지도와 지원 형식에서 특정한 주장에 대한 것이며, 판로·단위·퍼센트 의미를 잘못 지정한 지도를 정당화하지 않는다. 원문의 전체 주장·미검사 범위는 별도로 확인한다.

```text
python3 scripts/gg_body_plan_check.py --body <본문.md> --xlsx <재계산.xlsx> --map <계획값지도.json>
```

## 값 지도

전공별 엑셀의 주소를 공통 검사기에 하드코딩하지 않는다. 사용한 양식에서 확인한 채널·별칭·계획기간·셀 의미를 지도에 기록한다. `share`는 해당 채널의 전체 판매비율(0~1), `price`는 원/kg 단가 셀이다. 등급 하나의 비율이나 매출 비중을 전체 물량 비율로 오인하지 않는다. 합계·수식 셀은 Excel 재계산 캐시가 있어야 한다.

합성 예시(실제 계획·권장값 아님):

```json
{"channels":[{"name":"직거래","aliases":["직거래","온라인"],"years":{
  "2040":{"share":{"sheet":"판매계획","cell":"B2"},"price":{"sheet":"판매계획","cell":"C2"}},
  "2041":{"share":{"sheet":"판매계획","cell":"B3"},"price":{"sheet":"판매계획","cell":"C3"}}
}}]}
```

시작 연도는 지도에 등록한 전체 연속 계획기간에서 비율이 처음 양수가 되는 연도다. 기간 앞부분을 누락하지 않는다. 본문이 `직거래 2041년 소량 시작`이라면 시작 연도를, `2040년 직거래 15%`라면 판매비율을, `2040년 직거래 단가 2,400원/kg`이라면 단가를 검사한다. 퍼센트·단가는 본문 표시 소수 자릿수로 반올림해 대조한다. 각 결과에 원문 행·문장·셀 위치·실제값·기준값을 남긴다.

## 검사 범위와 발행 전 확인

- 자동 추출 후보는 등록 채널 별칭·네 자리 연도·시작/개시/진출/도입, `%`, `원/kg`가 한 행에 있는 주장이다. 첫 연도 앞 지표는 `not_checked`로 보존한다. 퍼센트·단가 수치 자체를 연도 토큰으로 세지 않는다.
- **지표 없이 이어지는 연도들은 하나의 귀속 묶음**이다. 나열(`및`·`과`·`와`·쉼표)은 나열된 각 연도, 범위(`-`·`–`·`—`·`−`·`~`·`∼`·`〜`·`부터`·`에서`)는 양 끝을 포함한 모든 연도에 공유 지표를 대입한다. `2041~2043년`처럼 묶음 안의 `년` 생략도 처리한다. 범위 내부 연도를 생략하지 않으며 하나라도 다르면 fail, 지도 밖의 연도는 blocked다. 연결 문법이 불명확하거나 범위가 역순이면 묶음 전체를 원문·행·채널·지표·후보 연도와 함께 `not_checked`로 남긴다. **일부 연도만 비교한 pass는 없다.**
- 지표가 두 연도 묶음 사이에 있어도 직전 연도에 무조건 배정하지 않는다. 앞 묶음의 마지막 연도 바로 뒤에 선택적 등록 별칭·지표 이름(비율: 판매비율/비율/비중, 단가: 단가/가격)·콜론과 공백만 거쳐 지표가 나오고, 다음 묶음 앞 구간이 공백뿐이거나 쉼표·세미콜론·세로줄·마침표로 닫힌 좁은 형식만 앞 묶음 전체와 비교한다. 다른 지표·연결 서술이 끼거나 `15%는 2042년`처럼 뒤 연도에도 연결될 수 있으면 `not_checked`다. 세 번째 이후 묶음에도 같은 규칙을 적용한다.
- 자유서술을 새로 해석하지 않으므로 `2027년 직거래 10%로 시작해 2030년 40%까지 늘린다` 같은 정상 연결 서술도 앞 연도 주장이 미검사로 남을 수 있다. 원문을 임의로 바꾸거나 이를 통과로 보고하지 않는다. 한 행 한 연도 또는 명시 연도→지표의 좁은 나열 형식에서 유효하며, 모호한 주장은 별도 구조화 대조로 확인한다. 마지막 연도 **묶음** 뒤의 기존 지표 대조도 묶음 전체에 적용한다. 다른 주장이 일치해도 미검사 항목이 남으면 전체 pass/exit 0이 될 수 없다. 표의 자유서술 셀도 같은 방식으로 검사한다.
- 행에 여러 채널이 있으면 자동 귀속하지 않고 `not_checked`로 남긴다. 연도가 열 머리에만 있는 표, 연도 생략·대명사·다른 가격 단위·다른 지표는 자동 판정 범위가 아니다. 지도와 본문의 해당 주장 목록을 사람이 대조하고 이 범위 밖은 기존 구조화 사실 대조 또는 별도 검토로 확인한다.
- 한 행에서 판매비율과 물가상승률 등 다른 퍼센트를 섞지 않는다. 그대로 검사하면 같은 채널의 판매비율 주장으로 해석한다. 원문을 임의 수정하지 말고 해당 문장을 별도 구조화 대조로 검토한다.
- 재계산 캐시 부재·지도 누락은 `blocked`, 대조할 주장 없음·모호한 귀속은 `not_checked`다. 둘 다 exit 2이며 통과가 아니다. 불일치는 exit 1, 비교한 주장에 불일치·미검사·차단이 없을 때만 exit 0이다. CLI JSON의 `summary.meaning`에 위 보조 검사 한계를 표시하며, **pass를 포함한 모든 결과**에 `summary.comparison_count`(시도한 연도×지표 비교 건수, blocked 포함), `summary.not_checked_count`(미검사로 기록된 지표/행 항목 수)를 함께 출력한다. 범위 내부의 각 연도도 비교 건수에 포함된다. `not_checked_count=0`도 본문 전체를 해석했다는 뜻은 아니며, 후보가 없는 본문은 두 개수가 모두 0이어도 not_checked다.
- 이 명령은 별도 발행 전 검사다. 기존 `gg.py check`의 금액 사실 대조를 대신하지 않으며 해당 명령에 자동 연결되었다고 주장하지 않는다. 최종 본문·요약 수정 뒤 다시 실행한다.
