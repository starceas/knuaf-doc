# 본문과 재무계획 대조

적용 범위: 모든 전공. 본문·요약·표 셀의 판로 시작 연도·판매비율·단가를 재계산한 재무 엑셀과 대조한다. 이전 본문의 값이나 다른 판로 값을 복사하지 않는다.

```text
python3 scripts/gg_body_plan_check.py --body <본문.md> --xlsx <재계산.xlsx> --map <계획값지도.json>
```

## 값 지도

전공별 엑셀의 주소를 공통 검사기에 하드코딩하지 않는다. 사용한 양식에서 확인한 채널·별칭·계획기간·셀 의미를 지도에 기록한다. `share`는 해당 채널의 전체 판매비율(0~1), `price`는 원/kg 단가 셀이다. 등급 하나의 비율이나 매출 비중을 전체 물량 비율로 오인하지 않는다. 합계·수식 셀은 Excel 재계산 캐시가 있어야 한다.

합성 예시(실제 계획·권장값 아님):

```json
{"channels":[{"name":"직거래","aliases":["직거래","온라인"],"years":{
  "2040":{"share":{"sheet":"판매계획","cell":"B2"},"price":{"sheet":"판매계획","cell":"C2"}},
  "2041":{"share":{"sheet":"판매계획","cell":"B3"},"price":{"sheet":"판매계획","cell":"C3"}}
}}]}
```

시작 연도는 지도에 등록한 전체 연속 계획기간에서 비율이 처음 양수가 되는 연도다. 기간 앞부분을 누락하지 않는다. 본문이 `직거래 2041년 소량 시작`이라면 시작 연도를, `2040년 직거래 15%`라면 판매비율을, `2040년 직거래 단가 2,400원/kg`이라면 단가를 검사한다. 퍼센트·단가는 본문 표시 소수 자릿수로 반올림해 대조한다. 각 결과에 원문 행·문장·셀 위치·실제값·기준값을 남긴다.

## 검사 범위와 발행 전 확인

- 자동 추출 범위는 채널 별칭·명시적 네 자리 연도·시작/개시/진출/도입, `%`, `원/kg`가 한 행에 있는 주장이다. 표의 자유서술 셀도 같은 방식으로 검사한다. 한 행의 다음 연도까지를 같은 연도 주장으로 본다.
- 행에 여러 채널이 있으면 자동 귀속하지 않고 `not_checked`로 남긴다. 연도가 열 머리에만 있는 표, 연도 생략·대명사·다른 가격 단위·다른 지표는 자동 판정 범위가 아니다. 지도와 본문의 해당 주장 목록을 사람이 대조하고 이 범위 밖은 기존 구조화 사실 대조 또는 별도 검토로 확인한다.
- 한 행에서 판매비율과 물가상승률 등 다른 퍼센트를 섞지 않는다. 그대로 검사하면 같은 채널의 판매비율 주장으로 해석한다. 원문을 임의 수정하지 말고 해당 문장을 별도 구조화 대조로 검토한다.
- 재계산 캐시 부재·지도 누락은 `blocked`, 대조할 주장 없음·모호한 다채널 행은 `not_checked`다. 둘 다 exit 2이며 통과가 아니다. 불일치는 exit 1, 관측한 주장 전부 일치할 때만 exit 0이다.
- 이 명령은 별도 발행 전 검사다. 기존 `gg.py check`의 금액 사실 대조를 대신하지 않으며 해당 명령에 자동 연결되었다고 주장하지 않는다. 최종 본문·요약 수정 뒤 다시 실행한다.
