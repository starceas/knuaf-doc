# 본문과 재무계획 대조

적용 범위: 모든 전공. 본문·요약·표 셀의 판로 시작 연도·판매비율·단가를 재계산한 재무 엑셀과 대조한다. 이전 본문의 값이나 다른 판로 값을 복사하지 않는다.

이 문장 숫자 대조는 **보조 경고, 판정 근거 아님**이다. 입력을 읽고 검증한 뒤에는 숫자 차이·미검사·일치·후보 없음 모두 **확인 권장** 경고로만 출력하고 exit 0을 반환한다. 본문이 맞거나 틀렸다고 확정하지 않으며 이 결과를 작성·발행 게이트에 연결하지 않는다. `각각`의 연도별 대응값이나 `15%에서 30%로`의 변화 서술도 공유 값으로 오해해 정상 문장에 경고할 수 있다. 정확한 문장 해석은 후속 과제다. 원문을 임의로 고치지 말고 엑셀·값 지도와 사람이 확인한다. 단 파일을 못 읽거나 지도를 검증하지 못하면 **확인 불가**로 차단한다.

```text
python3 scripts/gg_body_plan_check.py --body <본문.md> --xlsx <재계산.xlsx> --map <계획값지도.json>
```

## 값 지도

전공별 엑셀의 주소를 공통 검사기에 하드코딩하지 않는다. 사용한 양식에서 확인한 채널·별칭·계획기간·셀 의미를 지도에 기록한다. `share`는 해당 채널의 전체 판매비율(0~1), `price`는 원/kg 단가 셀이다. 등급 하나의 비율이나 매출 비중을 전체 물량 비율로 오인하지 않는다. 합계·수식 셀은 Excel 재계산 캐시가 있어야 한다.

합성 예시(실제 계획·권장값 아님):

```json
{"channels":[{"name":"직거래","aliases":["직거래","온라인"],"years":{
  "2040":{"share":{"sheet":"판매계획","cell":"B2"},"price":{"sheet":"판매계획","cell":"C2"}},
  "2041":{"share":{"sheet":"판매계획","cell":"B3"},"price":{"sheet":"판매계획","cell":"C3"}}
}}]}
```

시작 연도 참고값은 지도에 등록한 전체 연속 계획기간에서 비율이 처음 양수가 되는 연도다. 기간 앞부분을 누락하지 않는다. `직거래 2041년 소량 시작`, `2040년 직거래 15%`, `2040년 직거래 단가 2,400원/kg` 같은 표현에서 시작·비율·단가 후보를 추출한다. 퍼센트·단가는 본문 표시 소수 자릿수로 반올림해 참고값과 대조한다. 각 항목의 원문 행·문장·셀 위치·추출값·참고값을 남기며, 차이는 확정 오류가 아닌 확인 권장 사항이다.

## 검사 범위와 발행 전 확인

- 자동 추출 후보는 등록 채널 별칭·네 자리 연도·시작/개시/진출/도입, `%`, `원/kg`가 한 행에 있는 주장이다. 첫 연도 앞 지표는 `not_checked`로 보존한다. 퍼센트·단가 수치 자체를 연도 토큰으로 세지 않는다.
- 현재 추출기는 지표 없이 이어지는 연도들을 하나의 귀속 묶음 후보로 본다. 나열(`및`·`과`·`와`·쉼표)은 나열된 각 연도, 범위(`-`·`–`·`—`·`−`·`~`·`∼`·`〜`·`부터`·`에서`)는 양 끝과 내부 연도에 지표를 대입한다. `2041~2043년`처럼 묶음 안의 `년` 생략도 처리한다. 이 해석은 확정 사실이 아니다. 각 조합의 값 차이는 `warning`, 해석한 연도·지표의 참고값이 지도에 없으면 `not_checked`로 남길 뿐 작성을 막지 않는다. 연결 문법을 정하지 못하거나 범위가 역순이면 원문·행·채널·지표·후보 연도를 보존한다.
- 지표가 두 연도 묶음 사이에 있어도 직전 연도에 무조건 배정하지 않는다. 앞 묶음의 마지막 연도 바로 뒤에 선택적 등록 별칭·지표 이름(비율: 판매비율/비율/비중, 단가: 단가/가격)·콜론과 공백만 거쳐 지표가 나오고, 다음 묶음 앞 구간이 공백뿐이거나 쉼표·세미콜론·세로줄·마침표로 닫힌 좁은 형식만 앞 묶음 전체와 비교한다. 다른 지표·연결 서술이 끼거나 `15%는 2042년`처럼 뒤 연도에도 연결될 수 있으면 `not_checked`다. 세 번째 이후 묶음에도 같은 규칙을 적용한다.
- 자유서술을 정확히 해석하지 못하므로 `2027년 직거래 10%로 시작해 2030년 40%까지 늘린다` 같은 정상 연결 서술도 앞 연도 주장이 미검사로 남을 수 있다. 정상 `각각`·변화 범위 서술에서 잘못 만든 연도×값 조합의 경고도 발생한다. 마지막 묶음 뒤 지표를 포함해 어떤 결과도 본문 전체의 맞음·틀림을 증명하지 않는다. 미검사나 경고를 통과/실패 판정으로 보고하지 않으며 표의 자유서술 셀도 같은 보조 경고 범위다.
- 행에 여러 채널이 있으면 자동 귀속하지 않고 `not_checked`로 남긴다. 연도가 열 머리에만 있는 표, 연도 생략·대명사·다른 가격 단위·다른 지표는 자동 판정 범위가 아니다. 지도와 본문의 해당 주장 목록을 사람이 대조하고 이 범위 밖은 기존 구조화 사실 대조 또는 별도 검토로 확인한다.
- 한 행에서 판매비율과 물가상승률 등 다른 퍼센트를 섞지 않는다. 그대로 검사하면 같은 채널의 판매비율 주장으로 해석한다. 원문을 임의 수정하지 말고 해당 문장을 별도 구조화 대조로 검토한다.
- 입력을 읽고 지도를 검증하면 최상위 `status=warning`, `message=확인 권장`, exit 0이다. 비교 항목의 `match`는 추출값과 참고값이 수치상 같음, `warning`은 수치 차이, `not_checked`는 미검사라는 진단 구분일 뿐 문장 판정이 아니다. 지도에 없는 것으로 해석한 연도·지표도 미검사 경고로 남긴다.
- 손상·없는·읽을 수 없는 본문/엑셀/지도, 잘못된 지도 JSON·셀 참조·계획기간, 필요한 재계산 캐시 부재는 입력 확인 실패다. 이 경우는 `status=blocked`, `message=확인 불가`, 이유와 요약 JSON, exit 2를 내며 경고로 낮추지 않는다.
- CLI JSON `summary.meaning`에 **보조 경고, 판정 근거 아님**을 표시한다. 경고·확인 불가 모두 `summary.comparison_count`(시도한 연도×지표 비교 건수), `summary.not_checked_count`(기록된 미검사 항목 수)를 출력한다. 입력 확인 전에 실패하면 둘 다 0이다. 후보 없는 본문도 0/0 경고이며, 미검사 0은 전체 문장을 해석했다는 뜻이 아니다.
- 이 명령은 게이트가 아닌 별도 보조 경고다. 기존 `gg.py check`의 구조화 금액 사실 대조를 대신하거나 낮추지 않으며 해당 명령에 자동 연결하지 않는다. 정확한 문장 숫자 해석은 후속 과제로 넘긴다.
