# 재배방식·등급·판로에 맞는 재무 계획 규칙

> **적용 범위**: 규칙(1~4절)은 **모든 전공 공통**이다. 재배방식별 장비, 등급·판로 단가 차등은 작목 계획의 일반 원리다. 자동 검사(5절)는 학과 17시트 통합문서(`school_17_sheet_v1`)만 읽는다. 다른 양식은 같은 규칙을 사람이 확인한다.

양식이나 선배 파일에서 물려받은 행·단가를 "근거가 없으니 그대로 둔다"로 남기지 않는다. 쓰지 않는 장비·등급·판로는 지우거나 비우고, 쓰는 것은 근거로 값을 다르게 잡는다.

## 1. 재배방식별 장비·작업

- 계획을 세우기 전에 재배방식을 하나로 정한다: `open_field`(노지), `protected_soil`(시설 토경), `protected_soilless`(시설 수경, 고설·고형배지 포함), `mushroom`(버섯). 모르면 학생에게 묻는다.
- 방식별 대표 장비와 불필요 장비·작업은 [cultivation-fit.json](cultivation-fit.json)에 있다. 대표 장비는 인터뷰 예시일 뿐이고, 불필요 목록에 걸린 장비·작업만 검사가 막는다.
  - 시설 수경·버섯: 트랙터·관리기·경운기·로터리 같은 경운 기계와 경운·두둑·피복 작업이 없다.
  - 노지: 양액기·고설베드·환경제어기 같은 시설 수경 설비가 없다.
- 예시 장비 목록을 그대로 옮기지 않는다. 학생이 실제로 가진 장비와 살 장비만 적는다. 불필요 목록의 장비를 실제로 쓰면(예: 시설 토경 하우스 안 소형 관리기) 학생 확인을 받고 쓰는 작업을 각주에 밝힌다.
- 노무비 작업 항목도 재배방식에 맞춘다. 양식의 "경운" 같은 행은 수경이면 "정식·베드관리"처럼 실제 작업으로 바꾼다.

## 2. 미보유 자산·장비 행

- 보유하지 않거나 사지 않는 자산·장비는 **행을 지운다**. 금액 0원 행이나 "(미보유)" 표시 행으로 남기지 않는다. 투자계획·감가상각비계획·기초재무상태 모두 같다.
- 지울 때 합계 수식이 걸린 행은 수식을 남기고 항목명·규격·비고·금액 입력값만 비운다. 수식 범위를 바꾸지 않는다.
- 기초일에 없고 계획 기간에 살 자산(예: 첫해 매입 예정 토지)은 투자계획에만 둔다. 기초재무상태에 0원 행으로 미리 적지 않는다.

## 3. 품위(등급)별 단가

- **판매 비율이 0인 등급**은 단가·가격 이력을 비운다(또는 0). "상품만 출하" 같은 각주를 단다. 상품 단가를 중·하품 칸에 복사하지 않는다.
- **판매하는 등급**은 근거 있는 단가를 상 > 중 > 하 순서로 둔다. 판매하는 두 등급의 단가가 같거나 순서가 뒤집히면 검사가 막는다.
- **공식 자료에 등급 구분이 없으면**(등급 없는 평균 수취가 하나만 있는 경우) 상품 단일 등급으로 두고 중·하품 판매 비율을 0으로 한다. 각주에 "자료에 등급별 수량·가격이 없어 상품 단일 등급·중하품 0으로 둔 계획 가정"이라고 근거와 가정을 구분해 적는다.
- 등급 비율을 따로 정하면 그 비율의 근거(공식 자료의 상품화율·등급 비율, 학생 실측)를 각주에 적는다. 근거가 없으면 계획 가정이라고 밝힌다.

## 4. 판로별 단가와 판로 비용

- 판로마다 **거래단계가 맞는 출처**를 쓴다.
  - 수매·도매(공판장): 농가수취가, 도매시장 경락가.
  - 직거래(온라인·로컬·직판): 소매가.
- 두 판로 단가가 같으면 검사가 막는다. 한 판로 평균을 다른 판로에 복사하지 않는다. 한 판로 자료만 있으면 다른 판로는 판매하지 않는 계획으로 두거나, 그 판로 자료를 조사해 단가를 따로 잡는다.
- 판로 비용을 **어디에 반영했는지** 각주에 적는다. 둘 중 하나를 고르고 두 번 빼지 않는다.
  - 단가 차감: 소매가에서 택배비를 뺀 값을 직거래 단가로 쓴다.
  - 판매관리비: 단가는 출처 값 그대로 두고, 택배·포장비는 손익계획의 포장비·운반비, 공판장 수수료·운반비는 운반비·기타에 넣는다.
- 판로 비율·시작 연도는 본문 판매 계획과 같아야 한다.

합성 예(실제 자료 아님): 수매 상품 3,000원/kg(농가수취가 5년 평균), 직거래 상품 6,000원/kg(소매가 5년 평균), 직거래 1kg당 택배·포장 500원은 판매관리비 운반비·포장비에 넣고 단가에서는 빼지 않는다. 중·하품 0%, "공식 자료에 등급 구분 없음 → 상품 단일 등급 가정" 각주.

## 5. 자동 검사 `gg_plan_fit.py`

재계산된 통합문서 **사본**을 읽기만 한다.

```bash
python3 skills/knuaf-doc/scripts/gg_plan_fit.py <재계산된_통합문서.xlsx> --method protected_soilless \
  [--allow "소형관리기=하우스 안 두둑 정리에 사용(학생 확인)"]
```

종료 코드: 0 통과(경고만), 1 차단 오류, 2 검사 불가(`blocked`). `--method`에는 id나 이름(`고설수경`, `노지` 등)을 쓴다.

| 코드 | 수준 | 뜻 |
|---|---|---|
| `UNOWNED_ROW` | error | 투자계획·감가상각비계획에 이름은 있고 금액이 0이거나 빈 행 |
| `OPENING_ZERO_ROW` | warning | 기초재무상태에 금액 0인 자산 행(비고와 함께 사람이 판단) |
| `EQUIPMENT_METHOD_MISMATCH` | error | 재배방식 불필요 목록의 장비. `--allow`로 이유를 적으면 `EQUIPMENT_METHOD_EXCEPTION` warning |
| `TASK_METHOD_MISMATCH` / `TASK_METHOD_LABEL` | error / warning | 재배방식에 없는 노무 작업에 일수 배정 / 0일 행 이름만 남음 |
| `SALES_UNUSED_PRICE` | error | 판매 비율 0인 등급·판로에 단가나 가격 이력이 있음 |
| `SALES_PRICE_MISSING` | error | 판매하는 등급·판로에 단가 없음 |
| `GRADE_PRICE_EQUAL` / `GRADE_PRICE_ORDER` | error | 판매하는 등급끼리 단가 같음 / 상>중>하 역전 |
| `CHANNEL_PRICE_EQUAL` | error | 두 판로를 모두 파는 같은 등급의 단가가 같음 |
| `CHANNEL_COST_UNREFLECTED` | error | 판매관리비가 0이고 판로 비용 반영 각주도 없음 |
| `GRADE_BASIS_NOTE_MISSING` / `CHANNEL_SOURCE_NOTE_MISSING` | warning | 등급 구성 근거·판로 거래단계 출처 각주 없음 |
| `CULTIVATION_METHOD_UNDECLARED` | warning | `--method` 없음 — 장비·작업 대조 생략 |
| `PLAN_FIT_UNCACHED` 등 `blocked` | blocked | 수식 캐시 없음·양식을 읽지 못함. 통과가 아니다 |

한계:
- 장비·작업 대조는 이름 키워드 대조다. 목록에 없는 이름의 불필요 장비는 못 잡으므로 1절 규칙으로 사람이 본다.
- 각주 검사는 판매계획 시트 안의 각주 문장에서 낱말(등급·상품만·농가수취·소매·택배 등)이 있는지만 본다. 각주 내용이 맞는지는 사람이 확인한다.
- 레거시 17시트 생성기 경로는 `gg_school_verify`가 두 판로를 모두 팔 때 같은 단가를 막는다.
