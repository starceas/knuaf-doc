# 머리말: 선택의 계기와 각오

적용 범위: 모든 전공 공통 작성 정책. 학교 원문의 소주제·목차를 바꾸는 규정이 아니다. 머리말은 사업 요약이 아니라 학생이 왜 이 작목·지역·방식을 선택했는지 설명하는 이야기다.

## 인터뷰: 작문 전에 받을 답

1. 입학을 결심한 계기와 되고 싶은 농업인은 무엇인가?
2. 이 작목을 고르게 된 구체적인 장면·사건은 무엇인가?
3. 이 지역과 어떤 연고가 있으며 다른 후보지와 비교해 무엇을 직접 확인했는가?
4. 실습·견학에서 무엇을 직접 해 보았는가? 기간·업무·재배방식을 구분해 달라.
5. 작업 자세·몸의 부담 등 직접 겪은 문제가 방식 선택에 어떤 영향을 주었는가?
6. 시장·산업 흐름 중 어떤 기회를 보았는가? 확인한 사실과 개인의 인상을 나누어 달라.
7. 현재 인정해야 할 과제, 첫 작기에 확인할 것, 각오는 무엇인가?
8. 10년 뒤 어떤 농업인이 되고 싶은가?

원답변과 위치를 보존한다. 답에 없는 사연·연고·실습·도움·감정을 지어내지 않는다. 답이 ‘알아서’이면 이미 근거가 있는 본문에서만 선택의 기회를 구성한다. 학생 진술도 산업 전체의 사실을 증명하지 않는다.

## 네 문단 안팎, 실제 출력 1~2쪽

1. 입학 동기 → 어떤 농업인이 되려는지.
2. 기회 포착: 근거 있는 시장·산업 흐름 → 확인한 빈틈 → 본인이 발견한 기회. 이야기의 중심이다.
3. 무엇을·어디서·왜 이 방식: 학생의 경험·몸·연고가 선택으로 이어지게 쓴다. 규모 등 꼭 필요한 숫자만 남긴다.
4. 과제 인정 → 단계적 대응 → 각오·비전.

사업 개요 나열, 단가·매출·순이익·흑자 연도 같은 재무 결과, 본문 인용 괄호는 넣지 않는다. 필요한 사실의 상세 근거는 해당 본문 장과 작업 기록에 둔다. 짧은 산문을 쓰며 불필요한 소제목은 달지 않는다. 기존 분량 경고·상한은 thesis-level.md를 따른다.

## 문장 단위 근거 검사

인터뷰 → 작문 → 문장별 사실·근거 검토 → 수정 반영 순서다. 검토 기록에 문장, 판정(근거 있음 / 학생 진술 / 근거 없음), 근거 위치, 수정 내용을 남긴다.

- 통계·순위·최상급은 근거 범위와 일치해야 한다. ‘가장 큰 지역’, ‘가장 싼 토지’ 같은 무근거 순위는 삭제하거나 본인이 비교한 후보지 범위로 한정한다.
- 한 농가·한 작기 사례를 산업 전체의 보급 단계·생산성·관리 수준으로 일반화하지 않는다. 통계 부재는 현장 전체의 실태를 입증하지 않는다.
- 학생 답변이 본문 통계나 계획과 반대이면 그대로 쓰지 않고 확인·정정한다. 시설/노지 비중과 토경/수경 보급 비중을 혼동하지 않는다.
- 견학에서 본 방식 이름을 본인 계획에 옮기지 않는다. 작목·규모·재배방식·판로의 확정 상태는 본문·재무계획과 대조한다.
- 비전은 지향으로 쓰고, 아직 접촉하지 않은 조직·예정인 계약·계획값을 완료 사실이나 실증 성과로 쓰지 않는다.

자동 길이·어휘 검사는 이 근거 검토를 대신하지 않는다. 작성 참고 사례의 문장·학생 사실은 복사하지 않는다.
